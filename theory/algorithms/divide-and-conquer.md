# 분할 정복

> 분할-정복-결합, 거듭제곱 분할, 병합/퀵 정렬과의 관계

## 1. 정의 / 핵심 성질

### 1.1 분할 정복

#### 정의

문제를 같은 형태의 작은 부분 문제로 나누고(분할), 부분 문제를 재귀적으로 푼 뒤(정복), 그 결과를 합쳐(결합) 원래 문제의 답을 구하는 방법이다.

#### 구조

```
                 문제 (크기 n)
                /             \          ① 분할
       부분 문제 (n/2)     부분 문제 (n/2)
          /     \              /     \
       n/4     n/4          n/4     n/4   ② 정복 (충분히 작으면 직접 푼다)
          \     /              \     /
        부분 답               부분 답       ③ 결합
                \             /
                   전체 답
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 부분 문제가 서로 겹치지 않을 때 효과적이다 | 겹치면 같은 계산을 반복하게 되어 지수 시간이 된다. 이때는 동적 계획법을 쓴다 |
| 수행 시간은 점화식 `T(n) = a·T(n/b) + f(n)`으로 나타난다 | 크기 n/b인 부분 문제 a개를 풀고, 분할·결합에 f(n)이 든다 |
| 마스터 정리로 복잡도를 구한다 | `complexity.md`의 마스터 정리 참고 |
| 재귀 호출 비용과 스택 메모리가 든다 | 작은 크기에서는 단순한 방법(예: 삽입 정렬)으로 바꾸는 것이 빠르다 |

### 1.2 대표 알고리즘

| 알고리즘 | 분할 | 결합 | 점화식 | 복잡도 |
| --- | --- | --- | --- | --- |
| 이분 탐색 | 반으로, 한쪽만 탐색 | 없음 | `T(n/2) + 1` | `O(log n)` |
| 거듭제곱 `aⁿ` | 지수를 반으로 | 제곱 | `T(n/2) + 1` | `O(log n)` |
| 병합 정렬 | 반으로 | 병합 `O(n)` | `2T(n/2) + n` | `O(n log n)` |
| 퀵 정렬 | 피벗으로 분할 `O(n)` | 없음 | 평균 `2T(n/2) + n`, 최악 `T(n−1) + n` | 평균 `O(n log n)`, 최악 `O(n²)` |
| 퀵 셀렉트 (k번째 원소) | 피벗으로 분할, 한쪽만 | 없음 | 평균 `T(n/2) + n` | 평균 `O(n)`, 최악 `O(n²)` |
| 중앙값의 중앙값 선택 | 5개씩 묶어 피벗 결정 | 없음 | `T(n/5) + T(7n/10) + n` | 최악 `O(n)` |
| 카라츠바 곱셈 (n자리) | 반으로, 곱셈 3번 | 덧셈 | `3T(n/2) + n` | `O(n^1.585)` |
| 스트라센 행렬 곱 | 4블록, 곱셈 7번 | 덧셈 | `7T(n/2) + n²` | `O(n^2.807)` |
| 최근접 점 쌍 | x좌표 기준 반으로 | 가운데 띠 영역 검사 | `2T(n/2) + n` | `O(n log n)` |
| 하노이 탑 | n−1개 + 1개 | 없음 | `2T(n−1) + 1` | `O(2ⁿ)` |

### 1.3 거듭제곱

#### 정의

`aⁿ`을 지수를 반으로 나누어 계산하는 방법이다.
- n이 짝수: `aⁿ = (a^(n/2))²`
- n이 홀수: `aⁿ = a · (a^((n−1)/2))²`

#### 성질

| 성질 | 설명 |
| --- | --- |
| 곱셈 횟수가 `O(log n)`이다 | 지수가 매번 절반으로 줄어든다. 단순히 a를 n번 곱하면 `n − 1`번이다 |
| 모듈러 거듭제곱, 행렬 거듭제곱에 그대로 쓴다 | 곱셈의 결합 법칙만 성립하면 된다. 행렬 거듭제곱으로 피보나치 수를 `O(log n)`에 구한다 |

### 1.4 선택 문제 (k번째로 작은 원소)

| 방법 | 정의 | 성질과 설명 |
| --- | --- | --- |
| 퀵 셀렉트 | 퀵 정렬처럼 분할한 뒤, k번째 원소가 있는 쪽만 재귀한다 | 한쪽만 보므로 평균 `n + n/2 + n/4 + … ≤ 2n` = `O(n)`. 피벗이 치우치면 `O(n²)` |
| 중앙값의 중앙값 | 원소를 5개씩 묶어 각 묶음의 중앙값을 구하고, 그 중앙값들의 중앙값을 피벗으로 쓴다 | 이 피벗보다 작은 원소와 큰 원소가 각각 최소 `3n/10`개 보장된다. 따라서 남는 쪽은 최대 `7n/10`이고, `n/5 + 7n/10 < n`이므로 최악 `O(n)`이다 |

### 1.5 카라츠바 곱셈

#### 정의

큰 수의 곱셈에서 부분 곱을 4번이 아닌 3번만 계산하는 분할 정복 곱셈이다.
- `x = x1·10^m + x0`, `y = y1·10^m + y0`
- `x·y = x1y1·10^(2m) + (x1y0 + x0y1)·10^m + x0y0`

#### 성질

| 성질 | 설명 |
| --- | --- |
| 곱셈을 3번으로 줄인다 | `x1y0 + x0y1 = (x1 + x0)(y1 + y0) − x1y1 − x0y0`이므로, `x1y1`, `x0y0`, `(x1+x0)(y1+y0)` 세 번이면 된다 |
| `O(n^log₂3) ≈ O(n^1.585)`이다 | `T(n) = 3T(n/2) + O(n)`. 단순 곱셈은 `4T(n/2) + O(n)` = `O(n²)` |

### 1.6 스트라센 행렬 곱셈

#### 정의

2×2 블록으로 나눈 행렬 곱셈에서 블록 곱셈을 8번이 아닌 7번만 하는 분할 정복 알고리즘이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| `O(n^log₂7) ≈ O(n^2.807)`이다 | `T(n) = 7T(n/2) + O(n²)`. 단순 방법은 `8T(n/2) + O(n²)` = `O(n³)` |
| n이 작으면 오히려 느리다 | 덧셈·뺄셈이 18번으로 늘어나 상수 계수가 크다 |

### 용어 정리

- **분할 (divide)**: 문제를 같은 형태의 작은 문제로 나누는 단계
- **정복 (conquer)**: 작은 문제를 재귀적으로 푸는 단계
- **결합 (combine)**: 작은 문제의 답을 합치는 단계
- **기저 사례 (base case)**: 더 나누지 않고 직접 푸는 가장 작은 문제

| `T(n) = 2T(n/2) + O(1)` | `O(n)` |
| `T(n) = 2T(n/2) + O(n)` | `O(n log n)` |

| `T(n) = 3T(n/2) + O(n)` | `O(n^1.585)` |
| `T(n) = 7T(n/2) + O(n²)` | `O(n^2.807)` |
| `T(n) = 2T(n−1) + O(1)` | `O(2ⁿ)` |

## 3. 동작 과정

### 거듭제곱 a¹³

13 = 1101₂
- `a¹³ = a · (a⁶)²`
- `a⁶ = (a³)²`
- `a³ = a · (a¹)²`
- 곱셈: a³에 2번, a⁶에 1번, a¹³에 2번 → 5번 (단순 반복은 12번)

### 병합 정렬 재귀 트리

```
레벨 0:          n                → 병합 비용 n
레벨 1:      n/2     n/2          → n
레벨 2:   n/4 n/4  n/4 n/4        → n
  …
레벨 log n: 1 1 1 … 1             → n
```
레벨마다 n, 레벨 수 `log₂ n + 1` → `O(n log n)`

### 하노이 탑

원판 n개를 A → C (B 경유)
1. 위 n−1개를 A → B (C 경유)
2. 가장 큰 원판을 A → C
3. n−1개를 B → C (A 경유)
- 이동 횟수 `T(n) = 2T(n−1) + 1`, `T(1) = 1` → `2ⁿ − 1`
- n = 3: 7번 `A→C, A→B, C→B, A→C, B→A, B→C, A→C`

### 퀵 셀렉트 (3번째로 작은 수)

`[7, 2, 9, 4, 1]`, 피벗 7 → 작은 쪽 `[2, 4, 1]`(3개), 7, 큰 쪽 `[9]`
- 작은 쪽 크기 3 ≥ 3 → 작은 쪽에서 3번째 찾기
- `[2, 4, 1]`, 피벗 2 → `[1]`, 2, `[4]` → 작은 쪽 1개 + 피벗 → 피벗이 2번째, 3번째는 큰 쪽의 1번째 → 4

## 4. 비교

| 기준 | 분할 정복 | DP |
| --- | --- | --- |
| 부분 문제 | 독립 (겹치지 않음) | 겹침 |
| 방향 | 주로 top-down 재귀 | top-down 또는 bottom-up |
| 결과 저장 | 안 함 | 함 |
| 겹치는 문제에 분할 정복을 쓰면 | 같은 계산 반복 → 지수 시간 (피보나치 재귀) | |

| 기준 | 병합 정렬 | 퀵 정렬 |
| --- | --- | --- |
| 일이 많은 단계 | 결합 (병합) | 분할 (파티션) |
| 분할 균형 | 항상 반반 | 피벗에 따라 |
| 최악 | `O(n log n)` | `O(n²)` |

## 5. Python 구현 / 라이브러리

- 내장 `pow(a, b, m)`: 모듈러 거듭제곱 (분할 정복으로 구현됨)

```python
def power(a, n, mod):
    if n == 0:
        return 1
    half = power(a, n // 2, mod)
    res = half * half % mod
    if n % 2:
        res = res * a % mod
    return res
```

```python
# 반복문 버전 (비트 단위)
def power_iter(a, n, mod):
    res = 1
    a %= mod
    while n:
        if n & 1:
            res = res * a % mod
        a = a * a % mod
        n >>= 1
    return res
```

```python
# 행렬 거듭제곱으로 피보나치
def mat_mul(A, B, mod):
    return [[sum(A[i][k] * B[k][j] for k in range(2)) % mod for j in range(2)] for i in range(2)]

def fib(n, mod=10**9 + 7):
    res, base = [[1, 0], [0, 1]], [[1, 1], [1, 0]]
    while n:
        if n & 1:
            res = mat_mul(res, base, mod)
        base = mat_mul(base, base, mod)
        n >>= 1
    return res[0][1]
```

```python
def hanoi(n, src, via, dst, moves):
    if n == 0:
        return
    hanoi(n - 1, src, dst, via, moves)
    moves.append((src, dst))
    hanoi(n - 1, via, src, dst, moves)
```
