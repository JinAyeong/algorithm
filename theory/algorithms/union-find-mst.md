# 유니온 파인드 · 최소 신장 트리

> 유니온 파인드(경로 압축, union by rank), 크루스칼, 프림

## 1. 정의 / 핵심 성질

### 1.1 서로소 집합 (유니온 파인드)

#### 정의

서로 겹치지 않는 집합들을 관리하며 다음 두 연산을 지원하는 자료구조이다.
- `find(x)`: x가 속한 집합의 대표 원소(루트)를 반환한다.
- `union(x, y)`: x와 y가 속한 두 집합을 하나로 합친다.

#### 등장 배경

"두 원소가 같은 그룹인가?"를 반복해서 묻고 그룹을 계속 합쳐 나가는 문제(친구 관계, 네트워크 연결, 사이클 판별)를 빠르게 처리하기 위해 쓴다.

#### 구조

집합 하나를 트리 하나로 나타내고, 각 원소의 부모를 `parent` 배열에 저장한다. 루트는 자기 자신을 부모로 가진다.

```
집합 {1, 2, 3, 4}, {5, 6}

    1         5          parent = [_, 1, 1, 1, 3, 5, 5]
   / \        |                    0  1  2  3  4  5  6
  2   3       6
      |
      4
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 두 원소가 같은 집합인지는 `find(x) == find(y)`로 판단한다 | 같은 트리면 루트가 같다 |
| 루트의 `parent`에 자기 자신 대신 `−(집합 크기)`를 저장하기도 한다 | 음수면 루트임을 알 수 있고, 크기 정보도 함께 저장된다 |
| 최적화하지 않으면 `find`가 최악 `O(n)`이다 | 한쪽으로 길게 이어진 트리가 만들어질 수 있다 |
| 무방향 그래프의 사이클을 판별한다 | 간선 (u, v)를 추가하기 전에 u, v가 이미 같은 집합이면, 그 간선은 사이클을 만든다 |

### 1.2 유니온 파인드 최적화

| 기법 | 정의 | 설명 |
| --- | --- | --- |
| union by rank / size (가중 규칙) | 높이(또는 크기)가 작은 트리를 큰 트리의 루트 밑에 붙인다 | 트리 높이가 1 늘어나려면 크기가 최소 2배가 되어야 하므로, 높이가 `⌊log₂ n⌋ + 1` 이하로 유지된다 |
| 경로 압축 (붕괴 규칙) | `find`를 하면서 지나간 모든 노드를 루트에 직접 연결한다 | 다음 `find`부터는 한 번에 루트에 닿는다 |

```
경로 압축 전            find(4) 후
    1                      1
    |                   /  |  \
    2                  2   3   4
    |
    3
    |
    4
```

| 성질 | 설명 |
| --- | --- |
| 두 기법을 함께 쓰면 연산당 분할상환 `O(α(n))`이다 | α는 아커만 함수의 역함수로, 현실적인 n에서 4 이하이므로 사실상 상수이다 |

### 1.3 최소 신장 트리 (MST)

#### 정의

연결된 무방향 가중치 그래프에서, 모든 정점을 연결하는 트리(신장 트리) 중 간선 가중치의 합이 가장 작은 트리이다.

#### 등장 배경

여러 도시를 최소 비용의 도로나 통신망으로 모두 연결하는 문제처럼, 사이클 없이 전부 연결하면서 비용을 최소화해야 하는 문제를 푼다.

#### 구조

```
그래프                         MST (합 13)
A ──1── B                      A ──1── B
 \     / \                            / \
  3   2   4                          2   4
   \ /     \                        /     \
    C ──5── D                      C       D
     \     /                        \
      6   7                          6
       \ /                            \
        E                              E
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 간선이 `V − 1`개이고 사이클이 없다 | 트리이기 때문이다 |
| 컷 성질: 정점을 두 그룹으로 나눌 때, 두 그룹을 잇는 가장 가벼운 간선은 어떤 MST에 반드시 포함된다 | 그 간선을 빼고 다른 간선으로 두 그룹을 잇는 MST가 있다면, 그 간선과 바꾸면 합이 같거나 작아진다. 그리디 MST 알고리즘들이 옳은 근거이다 |
| 사이클 성질: 사이클에서 유일하게 가장 무거운 간선은 MST에 포함되지 않는다 | 그 간선을 빼도 사이클의 나머지 간선으로 연결이 유지된다 |
| 가중치가 모두 다르면 MST는 유일하다 | 컷 성질에서 고르는 간선이 매번 하나로 정해진다 |
| 음수 가중치가 있어도 된다 | 간선의 상대적 크기만 비교한다 |
| 최단 경로 트리와 다르다 | MST는 전체 합을 최소화하고, 최단 경로 트리는 출발점에서 각 정점까지의 거리를 최소화한다 |

### 1.4 크루스칼 알고리즘

#### 정의

간선을 가중치 오름차순으로 정렬한 뒤, 작은 간선부터 사이클을 만들지 않으면 선택하는 과정을 `V − 1`개를 고를 때까지 반복하는 MST 알고리즘이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 간선 중심이다 | 정렬된 간선을 하나씩 본다 |
| 중간 과정은 여러 트리(포리스트)이다 | 서로 떨어진 곳의 간선도 먼저 선택될 수 있다 |
| 사이클 판별에 유니온 파인드를 쓴다 | 두 끝점이 이미 같은 집합이면 사이클이다 |
| `O(E log E)`이다 | 간선 정렬이 대부분의 시간을 차지한다 |

### 1.5 프림 알고리즘

#### 정의

임의의 정점 하나로 시작하여, 현재 트리와 트리 밖 정점을 잇는 간선 중 가장 가벼운 간선을 선택해 트리를 키워 가는 MST 알고리즘이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 정점 중심이다 | 트리에 정점을 하나씩 추가한다 |
| 중간 과정이 항상 하나의 트리이다 | 트리에 붙은 간선만 고른다 |
| 이진 힙으로 `O(E log V)`, 배열로 `O(V²)`이다 | 배열 버전은 간선 수와 무관하므로 밀집 그래프에 유리하다 |
| 다익스트라와 구조가 같다 | 다익스트라는 "출발점부터의 거리", 프림은 "트리까지 잇는 간선 하나의 가중치"를 키로 쓴다 |

### 1.6 솔린 알고리즘 (Sollin / Borůvka)

#### 정의

처음에 각 정점을 하나의 트리로 보고, 단계마다 모든 트리가 각자 밖으로 나가는 가장 가벼운 간선을 동시에 선택하여 합쳐 가는 MST 알고리즘이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 단계 수는 `O(log V)`이다 | 단계마다 모든 트리가 다른 트리와 합쳐지므로 트리 수가 절반 이하로 줄어든다 |
| 전체 `O(E log V)`이다 | 단계마다 모든 간선을 한 번 확인한다 |
| 병렬 처리에 유리하다 | 각 트리의 최소 간선을 독립적으로 찾는다 |

### 용어 정리

- **대표 원소 (루트)**: 집합을 대표하는 원소. `find`의 결과
- **랭크**: 트리 높이의 상한값
- **신장 트리**: 그래프의 모든 정점을 포함하는 트리 형태의 부분 그래프
- **컷 (cut)**: 정점 집합을 두 부분으로 나누는 것
- **포리스트**: 트리들의 집합

## 2. 연산별 시간복잡도

| 유니온 파인드 | find | union |
| --- | --- | --- |
| 최적화 없음 | `O(n)` | `O(n)` (find 포함) |
| union by rank만 | `O(log n)` | `O(log n)` |
| 경로 압축만 | 분할상환 `O(log n)` | 분할상환 `O(log n)` |
| 둘 다 | 분할상환 `O(α(n))` | 분할상환 `O(α(n))` |

| MST 알고리즘 | 시간 | 적합한 그래프 |
| --- | --- | --- |
| 크루스칼 | `O(E log E)` = `O(E log V)` (정렬이 대부분) | 희소 |
| 프림 (배열) | `O(V²)` | 밀집 |
| 프림 (이진 힙) | `O(E log V)` | 희소 |
| 프림 (피보나치 힙) | `O(E + V log V)` | |
| 솔린 | `O(E log V)` | 병렬 |

## 3. 동작 과정

### 유니온 파인드

원소 1~6, union by size + 경로 압축
1. `union(1, 2)` → 2의 부모 1 (`{1, 2}`)
2. `union(3, 4)` → 4의 부모 3 (`{3, 4}`)
3. `union(2, 4)` → find(2) = 1, find(4) = 3, 크기 같음 → 3의 부모 1 (`{1, 2, 3, 4}`)
4. `union(5, 6)` → 6의 부모 5
5. `find(4)`: 4 → 3 → 1. 경로 압축으로 4의 부모를 1로 바꿈

```
3번 후          find(4) 후
    1               1
   / \            / | \
  2   3          2  3  4
      |
      4
```

### 크루스칼

간선: `A-B 1`, `B-C 2`, `A-C 3`, `B-D 4`, `C-D 5`, `C-E 6`, `D-E 7`

```
A ──1── B
 \     / \
  3   2   4
   \ /     \
    C ──5── D
     \     /
      6   7
       \ /
        E
```

| 간선 | 판단 | 선택 |
| --- | --- | --- |
| A-B 1 | 다른 집합 | O |
| B-C 2 | 다른 집합 | O |
| A-C 3 | A, C 같은 집합 (사이클) | X |
| B-D 4 | 다른 집합 | O |
| C-D 5 | 사이클 | X |
| C-E 6 | 다른 집합 | O → 4개 선택, 종료 |

MST: `A-B, B-C, B-D, C-E`, 합 13

### 프림 (A에서 시작)

| 트리 정점 | 후보 간선 | 선택 |
| --- | --- | --- |
| A | A-B 1, A-C 3 | A-B 1 |
| A, B | A-C 3, B-C 2, B-D 4 | B-C 2 |
| A, B, C | B-D 4, C-D 5, C-E 6 | B-D 4 |
| A, B, C, D | C-E 6, D-E 7 | C-E 6 |

합 13 (크루스칼과 같은 MST)

### 솔린

같은 그래프
- 1단계: A의 최소 A-B 1, B의 최소 A-B 1, C의 최소 B-C 2, D의 최소 B-D 4, E의 최소 C-E 6 → `A-B, B-C, B-D, C-E` 선택 → 트리 하나로 끝

## 4. 비교

| 기준 | 크루스칼 | 프림 | 솔린 |
| --- | --- | --- | --- |
| 중심 | 간선 | 정점 | 컴포넌트 |
| 중간 상태 | 포리스트 | 트리 하나 | 포리스트 |
| 필요한 자료구조 | 정렬 + 유니온 파인드 | 우선순위 큐 (또는 배열) | 유니온 파인드 |
| 유리한 그래프 | 희소 (`E ≈ V`) | 밀집 (`E ≈ V²`, 배열 버전) | 병렬 환경 |

## 5. Python 구현 / 라이브러리

```python
parent = list(range(n + 1))
size = [1] * (n + 1)

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]   # 경로 절반 압축
        x = parent[x]
    return x

def union(a, b):
    a, b = find(a), find(b)
    if a == b:
        return False
    if size[a] < size[b]:
        a, b = b, a
    parent[b] = a
    size[a] += size[b]
    return True
```

```python
def kruskal(n, edges):          # edges: (w, u, v)
    total, picked = 0, 0
    for w, u, v in sorted(edges):
        if union(u, v):
            total += w
            picked += 1
            if picked == n - 1:
                break
    return total
```

```python
import heapq

def prim(n, g, start=1):        # g[u] = [(w, v), ...]
    visited = [False] * (n + 1)
    pq = [(0, start)]
    total = 0
    while pq:
        w, u = heapq.heappop(pq)
        if visited[u]:
            continue
        visited[u] = True
        total += w
        for nw, v in g[u]:
            if not visited[v]:
                heapq.heappush(pq, (nw, v))
    return total
```
