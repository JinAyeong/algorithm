# 최단 경로

> 다익스트라, 벨만-포드, 플로이드-워셜 비교

## 1. 정의 / 핵심 성질

### 1.1 최단 경로 문제

#### 정의

가중치 그래프에서 두 정점 사이의 경로 중 간선 가중치의 합이 가장 작은 경로를 찾는 문제이다.

| 종류 | 정의 | 알고리즘 |
| --- | --- | --- |
| 단일 출발 | 한 정점에서 다른 모든 정점까지 | BFS(가중치 없음), 다익스트라, 벨만-포드, DAG 최단 경로 |
| 모든 쌍 | 모든 정점 쌍 사이 | 플로이드-워셜, 다익스트라를 V번 |

#### 완화 (relaxation)

현재 알고 있는 거리보다 u를 거쳐 가는 쪽이 짧으면 거리를 갱신하는 연산이다. 모든 최단 경로 알고리즘의 기본 연산이다.

```
if dist[u] + w(u, v) < dist[v]:
    dist[v] = dist[u] + w(u, v)
    prev[v] = u          # 경로 복원용

  s ──(dist[u]=3)──→ u ──(w=2)──→ v       dist[v]가 7이었다면 5로 갱신
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 최단 경로의 부분 경로도 최단 경로이다 | 부분 경로를 더 짧은 경로로 바꾸면 전체도 짧아지므로 모순이다 (최적 부분 구조) |
| 음수 사이클이 있으면 최단 경로가 정의되지 않는다 | 사이클을 돌 때마다 거리가 줄어 −∞가 된다 |
| 최단 경로는 간선을 최대 `V − 1`개 사용한다 | 음수 사이클이 없으면 사이클을 포함할 이유가 없으므로 단순 경로이다 |
| `prev`를 따라 거꾸로 가면 경로를 복원한다 | 마지막으로 갱신한 직전 정점이 최단 경로상의 이전 정점이다 |

### 1.2 다익스트라 알고리즘

#### 정의

아직 거리가 확정되지 않은 정점 중 거리가 가장 작은 정점을 골라 확정하고, 그 정점에서 나가는 간선을 완화하는 과정을 반복하는 단일 출발 최단 경로 알고리즘이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 음수 간선이 없어야 한다 | 가장 가까운 미확정 정점은 다른 정점을 거쳐도 더 가까워질 수 없다는 전제를 쓴다. 음수 간선이 있으면 나중에 더 짧은 경로가 생길 수 있다 |
| 그리디 알고리즘이다 | 매번 현재 가장 가까운 정점을 선택하고 되돌리지 않는다 |
| 배열로 구현하면 `O(V²)`이다 | 최솟값 정점을 V번 선형 탐색한다. 밀집 그래프에 유리하다 |
| 이진 힙으로 구현하면 `O((V + E) log V)`이다 | 최솟값 추출과 거리 갱신이 각각 `O(log V)`이다. 희소 그래프에 유리하다 |
| 피보나치 힙으로 구현하면 `O(E + V log V)`이다 | 거리 갱신(키 감소)이 분할상환 `O(1)`이다 |
| 힙 구현에서는 같은 정점이 여러 번 들어갈 수 있다 | 갱신할 때마다 새로 넣으므로, 꺼낼 때 저장된 거리보다 크면 무시한다 |

### 1.3 벨만-포드 알고리즘

#### 정의

모든 간선을 한 번씩 완화하는 과정을 `V − 1`번 반복하는 단일 출발 최단 경로 알고리즘이다.

#### 등장 배경

다익스트라는 음수 간선이 있으면 틀린 답을 낸다. 환율 차익, 비용 환급처럼 음수 가중치가 자연스러운 문제를 풀고, 음수 사이클의 존재를 판별하기 위해 쓴다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 음수 간선이 있어도 된다 | 확정 개념 없이 모든 간선을 반복해서 완화한다 |
| `V − 1`번 반복하면 충분하다 | 최단 경로는 간선이 최대 `V − 1`개이고, i번째 반복이 끝나면 간선 i개 이하인 최단 경로가 모두 확정된다 |
| `V`번째 반복에서도 갱신되면 음수 사이클이 있다 | 음수 사이클이 없으면 `V − 1`번 후에는 더 줄어들 수 없다 |
| 시간은 `O(VE)`이다 | 간선 E개를 V번 확인한다 |
| SPFA는 갱신된 정점의 간선만 다시 완화하는 개선판이다 | 평균은 빠르지만 최악은 같은 `O(VE)`이다 |

### 1.4 플로이드-워셜 알고리즘

#### 정의

모든 정점 쌍의 최단 거리를 동적 계획법으로 구하는 알고리즘이다.
- `D_k[i][j]`: 중간에 정점 1~k만 거칠 수 있을 때 i에서 j까지의 최단 거리
- `D_k[i][j] = min(D_(k−1)[i][j], D_(k−1)[i][k] + D_(k−1)[k][j])`

#### 구조

```
      i ──────────────→ j          k를 거치지 않는 경로
       ╲               ↗
        ╲             ╱
         ↘           ╱
              k                     k를 거치는 경로: D[i][k] + D[k][j]
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| k가 가장 바깥 반복문이어야 한다 | `D_k`는 `D_(k−1)` 전체가 완성된 뒤에 계산해야 한다. k를 안쪽에 두면 아직 갱신되지 않은 값을 쓴다 |
| 2차원 배열 하나로 덮어써도 된다 | k단계에서 `D[i][k]`와 `D[k][j]`는 바뀌지 않는다 (`D[k][k] = 0`이므로) |
| 시간 `O(V³)`, 공간 `O(V²)`이다 | 3중 반복, V×V 표 |
| 음수 간선은 되지만 음수 사이클은 안 된다 | 음수 사이클이 있으면 `D[i][i] < 0`이 되어 판별할 수 있다 |
| 경로 복원은 `nxt[i][j]`(i에서 다음으로 갈 정점) 또는 `via[i][j]`(거쳐 간 k)를 저장한다 | 갱신할 때 어떤 k를 거쳤는지 기록해 두고 재귀적으로 따라간다 |

### 1.5 DAG의 최단 경로

#### 정의

사이클이 없는 방향 그래프에서 위상 정렬 순서대로 각 정점의 나가는 간선을 완화하는 방법이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| `O(V + E)`이다 | 정점과 간선을 한 번씩만 처리한다 |
| 음수 간선이 있어도 된다 | 위상 순서상 앞의 정점은 이미 최종 거리가 정해져 있다 |
| 가중치의 부호를 바꾸면 최장 경로를 구한다 | 사이클이 없어 최장 경로가 잘 정의된다. AOE 네트워크의 임계 경로에 쓴다 |

### 용어 정리

- **완화 (relaxation)**: 더 짧은 경로를 찾으면 거리를 갱신하는 연산
- **음수 사이클**: 가중치 합이 음수인 사이클
- **단일 출발 / 모든 쌍 최단 경로**: 한 정점에서 출발 / 모든 정점 쌍
- **경로 복원**: 최단 거리뿐 아니라 실제 경로를 구하는 것

## 2. 연산별 시간복잡도

| 알고리즘 | 시간 | 공간 | 음수 간선 | 음수 사이클 검출 | 범위 |
| --- | --- | --- | --- | --- | --- |
| BFS | `O(V + E)` | `O(V)` | — (가중치 없음) | — | 단일 출발 |
| 0-1 BFS | `O(V + E)` | `O(V)` | X | — | 단일 출발 |
| 다익스트라 (배열) | `O(V²)` | `O(V)` | X | X | 단일 출발 |
| 다익스트라 (이진 힙) | `O(E log V)` | `O(V + E)` | X | X | 단일 출발 |
| 벨만-포드 | `O(VE)` | `O(V)` | O | O | 단일 출발 |
| DAG 최단 경로 | `O(V + E)` | `O(V)` | O | — (사이클 없음) | 단일 출발 |
| 플로이드-워셜 | `O(V³)` | `O(V²)` | O | O | 모든 쌍 |

## 3. 동작 과정

### 다익스트라

간선 (방향): `1→2 (4)`, `1→3 (1)`, `3→2 (2)`, `2→4 (1)`, `3→4 (5)`, `4→5 (3)`, 출발 1

| 단계 | 확정 | dist[1] | dist[2] | dist[3] | dist[4] | dist[5] |
| --- | --- | --- | --- | --- | --- | --- |
| 초기 | | 0 | ∞ | ∞ | ∞ | ∞ |
| 1 | 1 | **0** | 4 | 1 | ∞ | ∞ |
| 2 | 3 | 0 | 3 (1+2) | **1** | 6 (1+5) | ∞ |
| 3 | 2 | 0 | **3** | 1 | 4 (3+1) | ∞ |
| 4 | 4 | 0 | 3 | 1 | **4** | 7 |
| 5 | 5 | 0 | 3 | 1 | 4 | **7** |

최단 경로 1 → 5: `1 → 3 → 2 → 4 → 5` (길이 7)

### 다익스트라가 음수 간선에서 틀리는 예

간선 `1→2 (2)`, `1→3 (3)`, `3→2 (−2)`
1. 1 확정: dist2 = 2, dist3 = 3
2. 2 확정 (dist 2)
3. 3 확정 (dist 3) → `3→2` 완화하면 1이지만 2는 이미 확정
- 다익스트라 답 dist2 = 2, 실제 최단 1 (`1 → 3 → 2`)

### 벨만-포드

같은 그래프 `1→2 (2)`, `1→3 (3)`, `3→2 (−2)`, 간선 순서대로 완화

| 반복 | dist[1] | dist[2] | dist[3] |
| --- | --- | --- | --- |
| 초기 | 0 | ∞ | ∞ |
| 1 | 0 | 2 → 1 | 3 |
| 2 | 0 | 1 | 3 (변화 없음) |
| 3번째(검사) | 변화 없음 → 음수 사이클 없음 | | |

반복 1에서 `1→2`로 2, `1→3`으로 3, `3→2`로 1이 됨 (간선 순서에 따라 한 번에 여러 단계가 반영될 수 있음).

음수 사이클 예: `1→2 (1)`, `2→3 (−3)`, `3→2 (1)` → `2 → 3 → 2` 합 −2 → V번째 반복에도 계속 감소

### 플로이드-워셜

간선 `1→2 (4)`, `1→3 (7)`, `2→3 (1)`, `3→1 (2)`

초기
```
     1   2   3
1 [  0   4   7 ]
2 [  ∞   0   1 ]
3 [  2   ∞   0 ]
```
k = 1 (1을 경유): `D[3][2] = min(∞, D[3][1] + D[1][2]) = 2 + 4 = 6`
```
1 [  0   4   7 ]
2 [  ∞   0   1 ]
3 [  2   6   0 ]
```
k = 2 (2를 경유): `D[1][3] = min(7, D[1][2] + D[2][3]) = 4 + 1 = 5`
```
1 [  0   4   5 ]
2 [  ∞   0   1 ]
3 [  2   6   0 ]
```
k = 3 (3을 경유): `D[2][1] = min(∞, D[2][3] + D[3][1]) = 1 + 2 = 3`
```
1 [  0   4   5 ]
2 [  3   0   1 ]
3 [  2   6   0 ]
```

## 4. 비교

| 상황 | 선택 |
| --- | --- |
| 가중치 없음 | BFS |
| 가중치 0/1 | 0-1 BFS |
| 양수 가중치, 단일 출발 | 다익스트라 |
| 음수 간선 있음, 단일 출발 | 벨만-포드 |
| 음수 사이클 검출 | 벨만-포드 (또는 플로이드 `D[i][i] < 0`) |
| DAG | 위상 정렬 + 완화 |
| 모든 쌍, V가 작음 (~ 400) | 플로이드-워셜 |
| 모든 쌍, 희소 + 양수 | 다익스트라 V번 `O(VE log V)` |

| 기준 | 다익스트라 | 벨만-포드 | 플로이드-워셜 |
| --- | --- | --- | --- |
| 기법 | 그리디 | DP (간선 수 기준) | DP (경유 정점 기준) |
| 핵심 연산 | 최소 dist 정점 선택 + 완화 | 모든 간선 V−1번 완화 | 3중 반복 |
| 음수 간선 | X | O | O |

## 5. Python 구현 / 라이브러리

```python
import heapq

def dijkstra(start, g, n):
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

```python
def bellman_ford(start, edges, n):
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[start] = 0
    for i in range(n):
        updated = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
                if i == n - 1:
                    return None     # 음수 사이클
        if not updated:
            break
    return dist
```

```python
def floyd(n, edges):
    INF = float('inf')
    d = [[INF] * (n + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        d[i][i] = 0
    for u, v, w in edges:
        d[u][v] = min(d[u][v], w)
    for k in range(1, n + 1):
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d
```
