# 그래프 탐색 (BFS · DFS)

> BFS, DFS, 방문 처리, 상태 공간 탐색, 0-1 BFS

## 1. 정의 / 핵심 성질

### 1.1 깊이 우선 탐색 (DFS)

#### 정의

시작 정점에서 한 방향으로 갈 수 있는 데까지 깊이 들어갔다가, 더 갈 곳이 없으면 되돌아와(backtrack) 다른 방향을 탐색하는 방법이다. 스택 또는 재귀로 구현한다.

#### 구조

```
      1                 방문 순서: 1 → 2 → 4 → (되돌아옴) → 5 → 3
     / \
    2   3
   / \
  4   5
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 스택(재귀)으로 구현한다 | 가장 최근에 방문한 정점으로 되돌아가야 한다 (LIFO) |
| 최단 경로를 보장하지 않는다 | 먼저 도착한 경로가 깊이 들어간 먼 경로일 수 있다 |
| 메모리는 경로 깊이만큼 쓴다 | 스택에는 현재 경로 위의 정점만 쌓인다 |
| 사이클 검출, 위상 정렬, 단절점, SCC, 백트래킹에 쓴다 | 탐색 시작과 끝 시점, 되돌아가는 순서 정보를 활용한다 |

### 1.2 너비 우선 탐색 (BFS)

#### 정의

시작 정점에서 가까운 정점부터 차례로, 거리(간선 수) 1인 정점들을 모두 방문한 뒤 거리 2인 정점들을 방문하는 식으로 레벨 단위로 탐색하는 방법이다. 큐로 구현한다.

#### 구조

```
      1                 거리 0: 1
     / \                거리 1: 2, 3
    2   3               거리 2: 4, 5
   / \                  방문 순서: 1 → 2 → 3 → 4 → 5
  4   5
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 큐로 구현한다 | 먼저 발견한(가까운) 정점을 먼저 처리해야 한다 (FIFO) |
| 가중치가 없는 그래프에서 최단 거리를 보장한다 | 거리 d인 정점을 모두 처리한 뒤에야 거리 d+1인 정점을 처리하므로, 처음 방문했을 때의 거리가 곧 최단 거리이다 |
| 메모리는 한 레벨의 너비만큼 쓴다 | 큐에 같은 거리의 정점들이 한꺼번에 들어간다. 넓은 그래프에서는 DFS보다 많이 쓴다 |

### 1.3 방문 처리

#### 정의

같은 정점을 여러 번 탐색하지 않도록 방문한 정점을 표시하는 것이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| BFS는 큐에 **넣을 때** 방문 표시를 한다 | 꺼낼 때 표시하면, 아직 꺼내지 않은 정점이 다른 정점에서 다시 발견되어 큐에 중복으로 들어간다 |
| 재귀 DFS는 함수에 들어오자마자 표시한다 | 재귀 호출 자체가 스택 역할을 한다 |
| 스택 DFS는 **꺼낼 때** 표시하고, 이미 방문했으면 건너뛴다 | 이렇게 해야 재귀 DFS와 같은 방문 순서가 나온다 |
| 모든 정점과 간선을 한 번씩만 처리하므로 `O(V + E)`이다 (인접 리스트) | 각 정점은 한 번 방문되고, 각 간선은 양 끝에서 한 번씩 확인된다 |

### 1.4 DFS 간선 분류

#### 정의

방향 그래프를 DFS 하면 모든 간선이 다음 네 가지로 나뉜다.

| 간선 | 정의 |
| --- | --- |
| 트리 간선 | DFS가 새 정점을 발견할 때 지나간 간선 |
| 역방향 간선 (back edge) | 자손에서 조상으로 가는 간선 |
| 순방향 간선 (forward edge) | 조상에서 트리 간선이 아닌 경로로 자손으로 가는 간선 |
| 교차 간선 (cross edge) | 조상-자손 관계가 아닌 두 정점을 잇는 간선 |

#### 성질

| 성질 | 설명 |
| --- | --- |
| 역방향 간선이 있으면 사이클이 있다 | 조상 → (트리 간선들) → 자손 → 조상으로 돌아오는 경로가 생긴다 |
| 방향 그래프의 사이클은 "탐색 중"인 정점을 다시 만나는 것으로 검출한다 | 방문 상태를 미방문 / 탐색 중 / 완료로 나누면, 탐색 중인 정점은 현재 경로 위의 조상이다 |
| 무방향 그래프의 DFS에는 트리 간선과 역방향 간선만 있다 | 교차 간선이 될 간선은 먼저 방문한 쪽에서 트리 간선으로 처리된다 |

### 1.5 신장 트리

| 종류 | 정의 | 특징 |
| --- | --- | --- |
| DFS 신장 트리 | DFS가 지나간 간선으로 만든 트리 | 깊고 좁다 |
| BFS 신장 트리 | BFS가 지나간 간선으로 만든 트리 | 루트에서 각 정점까지의 경로가 최단 경로이다. 얕고 넓다 |

두 트리 모두 연결 그래프의 모든 정점을 포함하고 간선이 `V − 1`개이다.

### 1.6 탐색의 응용

| 응용 | 방법 | 설명 |
| --- | --- | --- |
| 연결 요소 개수 | 미방문 정점마다 탐색을 시작하고, 시작 횟수를 센다 | 한 번의 탐색은 한 연결 요소 전체를 방문한다 |
| 격자(grid) 탐색 | 칸을 정점, 상하좌우를 간선으로 본다 | 격자 문제를 그래프 탐색으로 바꿔 푼다 |
| 다중 시작점 BFS | 시작점 여러 개를 처음부터 큐에 넣고 시작한다 | 여러 곳에서 동시에 퍼지는 상황(불, 전염)을 한 번의 BFS로 처리한다 |
| 상태 공간 탐색 | 위치 외의 상태(벽 부순 횟수, 열쇠 보유 등)를 방문 배열의 차원에 포함한다 | 같은 위치라도 상태가 다르면 다른 정점이다 |
| 0-1 BFS | 가중치가 0 또는 1이면 덱을 쓰고, 0이면 앞에, 1이면 뒤에 넣는다 | 덱이 거리 순서를 유지하므로 우선순위 큐 없이 `O(V + E)`에 최단 거리를 구한다 |
| 양방향 BFS | 시작점과 도착점에서 동시에 탐색해 중간에서 만난다 | 탐색 범위가 `b^d`에서 `2·b^(d/2)`로 줄어든다 (b: 분기 수, d: 거리) |

### 용어 정리

- **방문 (visit)**: 정점을 처리하는 것
- **백트래킹 (backtrack)**: 더 갈 곳이 없을 때 이전 정점으로 되돌아가는 것
- **레벨**: BFS에서 시작점으로부터의 거리
- **조상 / 자손**: DFS 트리에서 현재 정점의 위쪽 / 아래쪽 정점

## 2. 연산별 시간복잡도

| 표현 | 시간 | 공간 |
| --- | --- | --- |
| 인접 리스트 | `O(V + E)` | `O(V)` (방문 배열 + 큐/스택) |
| 인접 행렬 | `O(V²)` | `O(V)` |
| 격자 N×M | `O(NM)` | `O(NM)` |

- 상태 공간 BFS: `O(상태 수 × 상태당 전이 수)`
- 재귀 DFS의 스택 깊이 최대 V → Python에서 재귀 한도 주의

## 3. 동작 과정

```
1 — 2 — 4
|   |
3   5
 \ /
  6
```
인접: `1: [2, 3]`, `2: [1, 4, 5]`, `3: [1, 6]`, `4: [2]`, `5: [2, 6]`, `6: [3, 5]` (번호 작은 순)

### DFS(1)

| 현재 | 동작 | 방문 순서 |
| --- | --- | --- |
| 1 | 2로 | 1 |
| 2 | 1 방문함, 4로 | 1 2 |
| 4 | 갈 곳 없음 → 2로 복귀 | 1 2 4 |
| 2 | 5로 | 1 2 4 5 |
| 5 | 6으로 | 1 2 4 5 6 |
| 6 | 3으로 | 1 2 4 5 6 3 |
| 3 | 갈 곳 없음 → 전부 복귀 | |

결과 `1 2 4 5 6 3`

### BFS(1)

| 꺼낸 정점 | 새로 넣은 정점 | 큐 | 거리 |
| --- | --- | --- | --- |
| | | 1 | 1:0 |
| 1 | 2, 3 | 2 3 | 2:1, 3:1 |
| 2 | 4, 5 | 3 4 5 | 4:2, 5:2 |
| 3 | 6 | 4 5 6 | 6:2 |
| 4 | | 5 6 | |
| 5 | (6 이미 방문) | 6 | |
| 6 | | | |

결과 `1 2 3 4 5 6`, 거리 `1:0, 2:1, 3:1, 4:2, 5:2, 6:2`

### 0-1 BFS

간선 `1→2 (0)`, `1→3 (1)`, `2→3 (0)`
- 덱 `[1]`, dist1 = 0
- 1 꺼냄: 2(가중치 0) → 앞에, dist2 = 0 / 3(가중치 1) → 뒤에, dist3 = 1 → 덱 `[2, 3]`
- 2 꺼냄: 3(가중치 0), 0 + 0 < 1 → dist3 = 0, 앞에 → 덱 `[3, 3]`
- 결과 dist3 = 0

## 4. 비교

| 기준 | DFS | BFS |
| --- | --- | --- |
| 자료구조 | 스택 / 재귀 | 큐 |
| 탐색 순서 | 깊이 먼저 | 가까운 것 먼저 (레벨) |
| 최단 거리 | 보장 안 함 | 가중치 없으면 보장 |
| 메모리 | 경로 깊이만큼 `O(h)` | 한 레벨 너비만큼 (넓으면 큼) |
| 해가 깊은 곳에 있을 때 | 유리 | 불리 |
| 무한 상태 공간 | 빠져나오지 못할 수 있음 | 가까운 해는 반드시 찾음 |
| 대표 용도 | 사이클, 위상 정렬, 백트래킹, 연결성 | 최단 거리, 최소 횟수 |

| 가중치 | 최단 경로 알고리즘 |
| --- | --- |
| 없음(모두 같음) | BFS `O(V + E)` |
| 0 또는 1 | 0-1 BFS `O(V + E)` |
| 양수 | 다익스트라 `O(E log V)` |
| 음수 포함 | 벨만-포드 `O(VE)` |

## 5. Python 구현 / 라이브러리

```python
from collections import deque

def bfs(start, g, n):
    dist = [-1] * (n + 1)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

```python
import sys
sys.setrecursionlimit(10 ** 6)

def dfs(u, g, visited, order):
    visited[u] = True
    order.append(u)
    for v in g[u]:
        if not visited[v]:
            dfs(v, g, visited, order)


def dfs_iter(start, g, n):
    visited = [False] * (n + 1)
    st, order = [start], []
    while st:
        u = st.pop()
        if visited[u]:
            continue
        visited[u] = True
        order.append(u)
        for v in reversed(g[u]):    # 작은 번호부터 방문하도록 역순 push
            if not visited[v]:
                st.append(v)
    return order
```

```python
# 격자 BFS
def grid_bfs(board, sr, sc):
    n, m = len(board), len(board[0])
    dist = [[-1] * m for _ in range(n)]
    dist[sr][sc] = 0
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < m and board[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist
```

```python
# 0-1 BFS
def zero_one_bfs(start, g, n):
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[start] = 0
    dq = deque([start])
    while dq:
        u = dq.popleft()
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if w == 0:
                    dq.appendleft(v)
                else:
                    dq.append(v)
    return dist
```
