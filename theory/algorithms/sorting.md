# 정렬

> 버블·선택·삽입·셸·병합·퀵·힙·계수·기수·버킷 정렬, 패스별 배열 상태, 안정성, 제자리 정렬 여부, 외부 정렬(합병 런, 선택 트리, 패자 트리)

## 1. 정의 / 핵심 성질

### 1.1 정렬의 분류

#### 정의

정렬은 원소들을 키의 대소 순서에 따라 나열하는 것이다. 다음 기준으로 분류한다.

| 기준 | 정의 |
| --- | --- |
| 안정 정렬 (stable) | 키가 같은 원소들의 원래 순서가 정렬 후에도 유지되는 정렬 |
| 제자리 정렬 (in-place) | 입력 배열 외에 `O(1)`(넓게는 `O(log n)`)의 추가 메모리만 쓰는 정렬 |
| 비교 정렬 | 두 원소의 대소 비교로만 순서를 정하는 정렬 |
| 비비교 정렬 | 키의 값(자릿수, 범위)을 직접 이용하는 정렬. 계수, 기수, 버킷 정렬 |
| 내부 / 외부 정렬 | 모든 데이터가 메모리에 있음 / 디스크를 함께 사용 |

#### 구조 (안정 정렬)

```
입력:          (3, a) (1, b) (3, c) (2, d)       ← (키, 이름)
안정 정렬:     (1, b) (2, d) (3, a) (3, c)       ← a가 c보다 앞 (원래 순서 유지)
불안정 정렬:   (1, b) (2, d) (3, c) (3, a)       ← 순서가 뒤바뀔 수 있음
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 여러 기준으로 정렬할 때 안정 정렬이 필요하다 | 이름순으로 정렬한 뒤 점수순으로 안정 정렬하면, 점수가 같은 사람은 이름순이 유지된다 |
| 인접한 원소만 교환하는 정렬은 안정하다 (버블, 삽입) | 같은 키끼리는 교환하지 않으므로 서로 앞지를 수 없다 |
| 멀리 떨어진 원소를 교환하는 정렬은 불안정하다 (선택, 셸, 퀵, 힙) | 교환 과정에서 같은 키를 건너뛰어 순서가 뒤바뀔 수 있다 |

### 1.2 비교 정렬의 하한

#### 정의

비교 정렬은 최악의 경우 `Ω(n log n)`번보다 적게 비교할 수 없다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 비교 정렬은 결정 트리로 나타낼 수 있다 | 내부 노드는 비교 한 번, 리프는 하나의 정렬 결과(순열)이다 |
| 리프는 최소 `n!`개이다 | 입력의 모든 순열을 구분해야 한다 |
| 높이(최악 비교 횟수)는 `log₂(n!) = Θ(n log n)` 이상이다 | 높이 h인 이진 트리의 리프는 최대 `2^h`개이므로 `2^h ≥ n!` |
| 병합·힙 정렬은 최적의 비교 정렬이다 | 최악이 `O(n log n)`으로 하한과 같다 |
| 계수·기수 정렬은 이 하한을 받지 않는다 | 비교를 하지 않는다 |

### 1.3 비교 정렬 알고리즘

| 정렬 | 정의 | 핵심 성질과 설명 |
| --- | --- | --- |
| 버블 | 인접한 두 원소를 비교해 순서가 틀리면 교환하는 과정을 반복한다 | 한 패스마다 남은 원소 중 최댓값이 맨 뒤로 간다. 교환이 없으면 정렬된 것이므로 조기 종료하면 최선 `O(n)`이다 |
| 선택 | 남은 구간에서 최솟값을 찾아 맨 앞 원소와 교환한다 | 입력과 관계없이 항상 `n(n−1)/2`번 비교한다. 교환은 최대 `n − 1`번으로 가장 적다 |
| 삽입 | 앞부분을 정렬 상태로 유지하며 새 원소를 알맞은 자리에 끼워 넣는다 | 이미 정렬된 입력은 원소마다 비교 1번이라 `O(n)`이다. 거의 정렬된 데이터에 가장 빠르다 |
| 셸 | 간격 h만큼 떨어진 원소끼리 삽입 정렬하고, 간격을 줄여 마지막에 h = 1로 끝낸다 | 멀리 있는 원소를 큰 간격으로 빨리 옮겨 두면 마지막 삽입 정렬이 거의 정렬된 데이터를 다룬다 |
| 병합 | 반으로 나눠 각각 정렬한 뒤, 정렬된 두 부분을 합친다 | 항상 반씩 나누므로 레벨 `log n`개, 레벨마다 병합 `O(n)` → 항상 `O(n log n)`. 병합에 보조 배열 `O(n)`이 필요하다 |
| 퀵 | 피벗을 기준으로 작은 값과 큰 값으로 나눈 뒤 각각 재귀 정렬한다 | 평균적으로 비슷하게 나뉘어 `O(n log n)`이고 상수가 작아 가장 빠르다. 피벗이 매번 최솟값/최댓값이면 `n − 1 : 0`으로 나뉘어 `O(n²)` |
| 힙 | 최대 힙을 만들고, 루트(최댓값)를 맨 뒤 원소와 교환하며 힙 크기를 줄인다 | 힙 생성 `O(n)` + 삭제 n번 `O(n log n)`. 추가 메모리 없이 최악 `O(n log n)`을 보장한다 |

#### 퀵 정렬의 피벗 선택

| 방법 | 특징 |
| --- | --- |
| 첫 원소 / 마지막 원소 | 이미 정렬된 입력에서 최악 `O(n²)`이 된다 |
| 중앙값-of-3 (첫·가운데·끝의 중앙값) | 정렬된 입력에서도 균형 있게 나뉜다 |
| 무작위 | 특정 입력이 항상 최악이 되는 것을 막는다 |

- 퀵 정렬의 평균 비교 횟수는 약 `1.39 n log₂ n`이다. 병합 정렬(약 `n log₂ n`)보다 비교는 많지만, 데이터 이동이 적고 캐시 효율이 좋아 실제로 더 빠르다.

#### 셸 정렬의 간격 수열

| 수열 | 최악 |
| --- | --- |
| Shell: `n/2, n/4, …, 1` | `O(n²)` |
| Knuth: `1, 4, 13, 40, …` (`h = 3h + 1`) | `O(n^1.5)` |

간격 수열에 따라 성능이 달라지며, 일반적인 평균 성능은 아직 정확히 분석되지 않았다.

### 1.4 비비교 정렬 알고리즘

| 정렬 | 정의 | 핵심 성질과 설명 |
| --- | --- | --- |
| 계수 (counting) | 값별 등장 횟수를 세고, 누적 합으로 각 값의 위치를 정한다 | 값의 범위 k가 작아야 한다. 입력을 뒤에서부터 배치하면 같은 값의 순서가 유지되어 안정하다 |
| 기수 (radix) | 낮은 자리(LSD) 또는 높은 자리(MSD)부터 자릿수별로 정렬을 반복한다 | LSD는 각 자릿수 정렬이 안정해야 한다. 앞 단계에서 정한 낮은 자리 순서를 다음 단계가 보존해야 하기 때문이다 |
| 버킷 (bucket) | 값의 범위를 구간(버킷)으로 나눠 넣고, 버킷별로 정렬한 뒤 이어 붙인다 | 값이 고르게 분포하면 버킷마다 원소가 몇 개뿐이라 평균 `O(n + k)`이다. 한 버킷에 몰리면 그 버킷의 정렬 복잡도가 된다 |

### 1.5 외부 정렬

#### 정의

메모리보다 큰 데이터를 디스크에 두고, 일부씩 메모리로 읽어 정렬하는 방법이다.

#### 등장 배경

수십 GB의 데이터는 메모리에 한 번에 올릴 수 없다. 또 디스크 접근은 메모리보다 수만 배 느리므로, 비교 횟수보다 디스크를 몇 번 읽고 쓰는지(패스 수)가 성능을 결정한다.

#### 구조

```
디스크의 데이터
   │ ① 메모리 크기만큼 읽어 내부 정렬 → 런(run)으로 저장
   ▼
[런1] [런2] [런3] [런4] [런5] [런6]
   │ ② k-way 합병 (k = 2)
   ▼
[  런1+2  ] [  런3+4  ] [  런5+6  ]      ← 패스 1
[       런1~4        ] [  런5+6  ]      ← 패스 2
[             정렬 완료            ]      ← 패스 3
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 합병 패스 수는 `⌈log_k (런 수)⌉`이다 | 한 패스마다 런 수가 1/k로 줄어든다 |
| k를 키우면 패스 수가 줄어든다 | 디스크 입출력 횟수가 줄어든다. 대신 k개 중 최솟값을 고르는 비용이 늘어난다 |
| 대체 선택(replacement selection)을 쓰면 런의 평균 길이가 메모리 크기의 약 2배이다 | 출력한 값보다 큰 새 입력은 같은 런에 이어 붙일 수 있다. 런 수가 줄어 패스 수가 줄어든다 |

### 1.6 선택 트리

#### 정의

k개 런의 맨 앞 원소 중 최솟값을 빠르게 고르기 위한 완전 이진 트리이다. 리프에 각 런의 현재 원소를 둔다.
- 승자 트리: 내부 노드에 두 자식 중 승자(작은 값)를 저장한다. 루트가 전체 최솟값이다.
- 패자 트리: 내부 노드에 패자(큰 값)를 저장하고, 최종 승자는 루트 위의 별도 노드에 둔다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 처음 구성은 `O(k)`이다 | 리프 k개에 대해 내부 노드 `k − 1`개를 한 번씩 비교한다 |
| 최솟값을 꺼낸 뒤 갱신은 `O(log k)`이다 | 새 원소가 들어온 리프에서 루트까지의 경로만 다시 비교한다 |
| 승자 트리는 갱신할 때 형제 노드와 비교해야 한다 | 경로상의 노드에는 방금 나간 승자가 저장되어 있어 비교 대상이 아니다 |
| 패자 트리는 경로상의 노드(저장된 패자)와만 비교하면 된다 | 그 노드의 패자가 곧 새 원소의 상대이다. 형제를 찾을 필요가 없어 구현이 단순하다 |

### 용어 정리

- **패스 (pass)**: 데이터 전체를 한 번 훑는 단계
- **런 (run)**: 정렬된 연속 구간
- **피벗 (pivot)**: 퀵 정렬에서 분할의 기준이 되는 원소
- **k-way 합병**: 정렬된 k개 런을 한 번에 합치는 것
- **결정 트리**: 비교 결과에 따라 갈라지는 경로로 알고리즘의 동작을 나타낸 트리

## 2. 연산별 시간복잡도

| 정렬 | 최선 | 평균 | 최악 | 공간 | 안정 | 제자리 |
| --- | --- | --- | --- | --- | --- | --- |
| 버블 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | O | O |
| 선택 | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | X | O |
| 삽입 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | O | O |
| 셸 | `O(n log n)` | 간격에 따라 `O(n^1.3~1.5)` | `O(n²)` | `O(1)` | X | O |
| 병합 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | O | X |
| 퀵 | `O(n log n)` | `O(n log n)` | `O(n²)` | `O(log n)` | X | O |
| 힙 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)` | X | O |
| 계수 | `O(n + k)` | `O(n + k)` | `O(n + k)` | `O(n + k)` | O | X |
| 기수 | `O(d(n + k))` | `O(d(n + k))` | `O(d(n + k))` | `O(n + k)` | O | X |

- k: 값 범위(계수) 또는 기수(기수 정렬의 진법), d: 자릿수
- 버블 최선 `O(n)`은 "교환 없으면 종료" 처리를 했을 때
- 병합 정렬은 연결 리스트로 하면 추가 공간 `O(1)`에 가능
- 퀵 정렬 공간은 재귀 스택. 최악에는 `O(n)`

| 정렬 | 비교 횟수 | 교환(이동) 횟수 |
| --- | --- | --- |
| 버블 | 최악 `n(n−1)/2` | 최악 `n(n−1)/2` |
| 선택 | 항상 `n(n−1)/2` | 항상 `n − 1` 이하 |
| 삽입 | 최선 `n − 1`, 최악 `n(n−1)/2` | 최악 `n(n−1)/2` |

## 3. 동작 과정

입력 `[5, 2, 4, 6, 1, 3]`, 오름차순

### 버블

| 패스 | 결과 | 확정 |
| --- | --- | --- |
| 1 | `[2, 4, 5, 1, 3, 6]` | 6 |
| 2 | `[2, 4, 1, 3, 5, 6]` | 5 |
| 3 | `[2, 1, 3, 4, 5, 6]` | 4 |
| 4 | `[1, 2, 3, 4, 5, 6]` | 3 |
| 5 | 교환 없음 → 종료 | |

패스 1 상세: `5↔2` → `5↔4` → `5, 6` 그대로 → `6↔1` → `6↔3`

### 선택

| 패스 | 최솟값 | 결과 |
| --- | --- | --- |
| 1 | 1 (인덱스 4) ↔ 인덱스 0 | `[1, 2, 4, 6, 5, 3]` |
| 2 | 2 (제자리) | `[1, 2, 4, 6, 5, 3]` |
| 3 | 3 (인덱스 5) ↔ 인덱스 2 | `[1, 2, 3, 6, 5, 4]` |
| 4 | 4 (인덱스 5) ↔ 인덱스 3 | `[1, 2, 3, 4, 5, 6]` |
| 5 | 5 (제자리) | `[1, 2, 3, 4, 5, 6]` |

### 삽입

| 단계 | 삽입할 값 | 결과 |
| --- | --- | --- |
| 1 | 2 | `[2, 5, 4, 6, 1, 3]` |
| 2 | 4 | `[2, 4, 5, 6, 1, 3]` |
| 3 | 6 | `[2, 4, 5, 6, 1, 3]` |
| 4 | 1 | `[1, 2, 4, 5, 6, 3]` |
| 5 | 3 | `[1, 2, 3, 4, 5, 6]` |

### 셸 (간격 3 → 1)

- 간격 3: 그룹 `(5, 6)`, `(2, 1)`, `(4, 3)` 각각 정렬 → `[5, 1, 3, 6, 2, 4]`
- 간격 1: 삽입 정렬 → `[1, 2, 3, 4, 5, 6]`

### 퀵 (첫 원소 피벗, 양쪽 포인터)

- 왼쪽 포인터 i: 피벗보다 **큰** 값을 찾을 때까지 오른쪽으로
- 오른쪽 포인터 j: 피벗보다 **작은** 값을 찾을 때까지 왼쪽으로
- `i < j`면 교환, 엇갈리면 피벗과 `a[j]` 교환 → 피벗 위치 확정

피벗 5
1. i → 6 (인덱스 3), j → 3 (인덱스 5) → 교환 `[5, 2, 4, 3, 1, 6]`
2. i → 6 (인덱스 5), j → 1 (인덱스 4) → 엇갈림
3. 피벗 5 ↔ `a[4]` → `[1, 2, 4, 3, 5, 6]`
- 5 확정. 왼쪽 `[1, 2, 4, 3]`, 오른쪽 `[6]`을 재귀

최악 예: `[1, 2, 3, 4, 5]`에 첫 원소 피벗 → 분할이 매번 `0 : n−1` → 비교 `n(n−1)/2`

### 병합

```
[5, 2, 4, 6, 1, 3]
[5, 2, 4]          [6, 1, 3]
[5]  [2, 4]        [6]  [1, 3]
[5]  [2] [4]       [6]  [1] [3]
[5]  [2, 4]        [6]  [1, 3]
[2, 4, 5]          [1, 3, 6]
[1, 2, 3, 4, 5, 6]
```
- 병합: 두 리스트 앞에서부터 작은 값을 꺼냄. 같으면 **왼쪽을 먼저** → 안정

### 힙

1. 최대 힙 만들기 (bottom-up): `[5, 2, 4, 6, 1, 3]` → `[6, 5, 4, 2, 1, 3]`
   - i=3: 4 vs 자식 3 → 그대로
   - i=2: 2 vs 자식 6, 1 → 6과 교환 `[5, 6, 4, 2, 1, 3]`
   - i=1: 5 vs 자식 6, 4 → 6과 교환 `[6, 5, 4, 2, 1, 3]`, 5 vs 자식 2, 1 → 그대로
2. 루트를 끝과 교환하고 힙 크기 −1, down-heap 반복

| 단계 | 교환 후 down-heap | 정렬된 뒷부분 |
| --- | --- | --- |
| 1 | `[5, 3, 4, 2, 1]` | `6` |
| 2 | `[4, 3, 1, 2]` | `5, 6` |
| 3 | `[3, 2, 1]` | `4, 5, 6` |
| 4 | `[2, 1]` | `3, 4, 5, 6` |
| 5 | `[1]` | `2, 3, 4, 5, 6` |

### 계수

입력 `[2, 5, 3, 0, 2, 3, 0, 3]`, 값 범위 0~5
1. 개수: `C = [2, 0, 2, 3, 0, 1]` (값 0이 2개, 2가 2개, 3이 3개, 5가 1개)
2. 누적: `C = [2, 2, 4, 7, 7, 8]` → 값 v의 마지막 위치 = `C[v] − 1`
3. 입력을 **뒤에서부터** 읽어 `C[v]`를 1 줄이고 그 자리에 놓음 → 안정
- 결과 `[0, 0, 2, 2, 3, 3, 3, 5]`

### 기수 (LSD)

입력 `[170, 45, 75, 90, 802, 24, 2, 66]`

| 기준 자리 | 결과 |
| --- | --- |
| 1의 자리 | `[170, 90, 802, 2, 24, 45, 75, 66]` |
| 10의 자리 | `[802, 2, 24, 45, 66, 170, 75, 90]` |
| 100의 자리 | `[2, 24, 45, 66, 75, 90, 170, 802]` |

- 10의 자리에서 802와 2는 둘 다 0. 앞 단계 순서(802가 앞)를 유지해야 함 → 각 자리 정렬이 안정해야 하는 이유

### 불안정 예 (선택 정렬)

`[2a, 2b, 1]` → 최솟값 1과 맨 앞 2a 교환 → `[1, 2b, 2a]` → 같은 키 2의 순서가 뒤바뀜

### 외부 정렬 계산

레코드 4,500개, 메모리 750개
- 런 수: `4500 / 750 = 6`
- 2-way 합병 패스 수: `⌈log₂ 6⌉ = 3` (6 → 3 → 2 → 1)
- 3-way 합병 패스 수: `⌈log₃ 6⌉ = 2` (6 → 2 → 1)
- 대체 선택을 쓰면 런 길이 평균 약 1,500 → 런 3개 → 2-way 2패스

### 패자 트리 (k = 4)

런 첫 원소 `R0: 10, R1: 6, R2: 8, R3: 15`
```
          [승자 6]
             |
            (8)          ← 결승의 패자
          /     \
       (10)     (15)     ← 1라운드 패자
       /  \     /  \
     10    6   8    15
     R0   R1  R2    R3
```
- 6 출력 → R1의 다음 원소(예: 12)를 리프에 넣음
- 경로상 패자들과만 비교: 12 vs 10 → 10 승, 12가 패자로 남음 → 10 vs 8 → 8 승, 10이 패자로 남음 → 새 승자 8

## 4. 비교

| 상황 | 적합한 정렬 |

## 5. Python 구현 / 라이브러리

- `sorted(iterable)`는 새 리스트, `list.sort()`는 제자리
- 알고리즘: Timsort (병합 + 삽입). 안정, 최선 `O(n)`, 최악 `O(n log n)`, 공간 `O(n)`
- `key=`: `sorted(a, key=lambda x: (-x[1], x[0]))` → 2번째 내림차순, 1번째 오름차순
- `reverse=True`도 안정성 유지
- 비교 함수: `functools.cmp_to_key`

```python
def quick_sort(a, lo, hi):
    if lo >= hi:
        return
    pivot = a[lo]
    i, j = lo + 1, hi
    while True:
        while i <= hi and a[i] <= pivot:
            i += 1
        while j > lo and a[j] >= pivot:
            j -= 1
        if i >= j:
            break
        a[i], a[j] = a[j], a[i]
    a[lo], a[j] = a[j], a[lo]
    quick_sort(a, lo, j - 1)
    quick_sort(a, j + 1, hi)
```

```python
def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    res, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:     # <= 로 안정성 유지
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    return res + left[i:] + right[j:]
```

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
```

```python
def counting_sort(a, k):
    cnt = [0] * (k + 1)
    for x in a:
        cnt[x] += 1
    for v in range(1, k + 1):
        cnt[v] += cnt[v - 1]
    out = [0] * len(a)
    for x in reversed(a):
        cnt[x] -= 1
        out[cnt[x]] = x
    return out
```
