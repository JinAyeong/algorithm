# 투 포인터 · 슬라이딩 윈도우 · 누적 합

> 투 포인터, 슬라이딩 윈도우, 1차원/2차원 누적 합

## 1. 정의 / 핵심 성질

### 1.1 투 포인터

#### 정의

배열 위의 두 위치를 가리키는 포인터 두 개를 조건에 따라 움직이며 답을 찾는 기법이다.

#### 등장 배경

"합이 S인 두 수", "조건을 만족하는 연속 구간"을 모든 쌍에 대해 확인하면 `O(n²)`이다. 정렬이나 단조성을 이용하면 한 번 지나간 위치를 다시 볼 필요가 없어, 포인터를 한 방향으로만 움직여 `O(n)`에 풀 수 있다.

#### 구조

```
양 끝에서 안쪽으로 (정렬된 배열, 합 = 10 찾기)
[ 1   2   3   4   6   8   11 ]
  ↑                        ↑
  l                        r     합 12 > 10 → r을 왼쪽으로
                                 합 < 10   → l을 오른쪽으로

같은 방향으로 (연속 구간)
[ 2   3   1   2   4   3 ]
  ↑       ↑
  l       r      조건 미달 → r을 오른쪽으로 (구간 확장)
                 조건 만족 → l을 오른쪽으로 (구간 축소)
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 전체가 `O(n)`이다 | 두 포인터가 각각 최대 n번만 움직이고 뒤로 가지 않는다 |
| 양 끝 방식은 배열이 정렬되어 있어야 한다 | 합이 크면 r을 줄이고 작으면 l을 늘리는 판단이 정렬 순서에 기대고 있다 |
| 양 끝 방식에서 버린 쌍은 다시 볼 필요가 없다 | 합이 목표보다 크면, 현재 r과 l 이후의 어떤 원소를 짝지어도 더 크다 |
| 같은 방향 방식은 구간을 넓힐수록 값이 단조 증가해야 한다 | 원소가 모두 양수이면 구간을 넓히면 합이 늘고 좁히면 준다. 음수가 섞이면 성립하지 않는다 |
| 정렬된 두 배열의 병합, 교집합도 투 포인터로 `O(n + m)`에 구한다 | 두 배열에 포인터를 하나씩 두고 작은 쪽을 전진시킨다 |

### 1.2 슬라이딩 윈도우

#### 정의

일정한 길이(또는 조건)의 구간을 한 칸씩 밀면서, 새로 들어오는 원소와 빠지는 원소만 반영해 구간의 값을 갱신하는 기법이다.

#### 구조

```
길이 3인 구간의 합
[ 1   3   2   6   4 ]
 └──────┘               합 6
     └──────┘           6 − 1 + 6 = 11
         └──────┘       11 − 3 + 4 = 12
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 구간마다 `O(1)`에 갱신한다 | 매번 구간 전체를 다시 더하지 않고 양 끝만 반영한다 |
| 길이가 변하는 윈도우는 같은 방향 투 포인터와 같다 | 오른쪽 끝을 늘리고 왼쪽 끝을 줄이는 방식이다 |
| 윈도우 안의 원소 종류 수는 딕셔너리로 개수를 관리해 구한다 | 들어올 때 +1, 나갈 때 −1 하고 0이 되면 삭제한다 |
| 윈도우 안의 최댓값은 단조 덱으로 전체 `O(n)`에 구한다 | 덱에 값이 감소하는 순서로 인덱스를 유지하면 맨 앞이 최댓값이다. 각 원소는 한 번 들어가고 한 번 나온다 |

### 1.3 누적 합

#### 정의

배열의 앞에서부터 원소를 차례로 더한 값을 미리 저장해 두고, 구간 합을 두 누적 합의 차이로 구하는 기법이다.
- `P[0] = 0`, `P[i] = a[0] + a[1] + … + a[i−1]`
- `a[l] + … + a[r] = P[r+1] − P[l]`

#### 구조

```
a = [ 3   1   4   1   5 ]
P = [ 0   3   4   8   9   14 ]

a[1] + a[2] + a[3] = P[4] − P[1] = 9 − 3 = 6
                     (0~3번 합) − (0번 합)
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 전처리 `O(n)`, 구간 합 질의 `O(1)`이다 | 누적 합을 한 번 계산해 두면 질의마다 뺄셈 한 번이다 |
| 원소가 바뀌면 누적 합을 다시 계산해야 한다 (`O(n)`) | 바뀐 원소 뒤의 모든 누적 합이 달라진다. 갱신이 잦으면 펜윅 트리나 세그먼트 트리(`O(log n)`)를 쓴다 |
| 합이 K인 연속 구간의 개수를 `O(n)`에 센다 | `P[j] − P[i] = K`인 쌍의 수이므로, 지금까지 나온 누적 합의 횟수를 해시맵에 저장해 두면 된다. 음수가 있어도 된다 |

### 1.4 2차원 누적 합

#### 정의

`S[i][j]`를 (1, 1)부터 (i, j)까지 직사각형 영역의 합으로 저장해 두고, 임의 직사각형의 합을 포함-배제로 구하는 기법이다.

#### 구조

```
(x1, y1) ~ (x2, y2)의 합을 구할 때

  ┌─────────┬───────────┐
  │    D    │     B     │        구하는 영역 = (전체) − (D+B) − (D+C) + D
  ├─────────┼───────────┤        = S[x2][y2] − S[x1−1][y2] − S[x2][y1−1] + S[x1−1][y1−1]
  │    C    │  구하는   │
  │         │   영역    │        D는 두 번 빠졌으므로 한 번 더한다
  └─────────┴───────────┘
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 만들기: `S[i][j] = a[i][j] + S[i−1][j] + S[i][j−1] − S[i−1][j−1]` | 위쪽과 왼쪽 영역을 더하면 겹치는 왼쪽 위 영역이 두 번 더해진다 |
| 전처리 `O(NM)`, 질의 `O(1)`이다 | 질의마다 덧셈·뺄셈 세 번이다 |

### 1.5 차분 배열

#### 정의

구간 `[l, r]`에 v를 더하는 갱신을 `D[l] += v`, `D[r+1] −= v` 두 칸에만 기록해 두었다가, 마지막에 누적 합으로 실제 배열을 복원하는 기법이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 구간 갱신이 `O(1)`, 복원이 `O(n)`이다 | 누적 합을 하면 l부터 v가 더해지고 r+1부터 다시 빠진다 |
| 갱신이 모두 끝난 뒤 한 번만 결과를 볼 때 쓴다 | 중간에 값을 보려면 매번 복원해야 한다 |
| 2차원에도 쓸 수 있다 | 직사각형 네 모서리에 `+v, −v, −v, +v`를 기록하고 가로·세로로 누적한다 |

### 용어 정리

- **포인터**: 배열의 위치(인덱스)를 가리키는 변수
- **윈도우**: 현재 보고 있는 연속 구간
- **누적 합 (prefix sum)**: 처음부터 각 위치까지의 합
- **포함-배제**: 겹치는 부분을 빼고 더해 정확한 합을 구하는 원리
- **단조성**: 한 방향으로만 증가(또는 감소)하는 성질

## 2. 연산별 시간복잡도

| 기법 | 전처리 | 질의/전체 | 공간 |
| --- | --- | --- | --- |
| 투 포인터 | 정렬 `O(n log n)` (필요 시) | `O(n)` | `O(1)` |
| 슬라이딩 윈도우 (합) | 없음 | `O(n)` | `O(1)` |
| 슬라이딩 윈도우 최댓값 (단조 덱) | 없음 | `O(n)` | `O(k)` |
| 1차원 누적 합 | `O(n)` | 구간 합 `O(1)` | `O(n)` |
| 2차원 누적 합 | `O(NM)` | 구간 합 `O(1)` | `O(NM)` |
| 차분 배열 | — | 갱신 `O(1)`, 복원 `O(n)` | `O(n)` |
| 펜윅/세그먼트 트리 | `O(n)` | 갱신·질의 `O(log n)` | `O(n)` |

## 3. 동작 과정

### 두 수의 합 (양 끝)

`[1, 2, 3, 4, 6, 8, 11]`, 목표 10

| l | r | 합 | 동작 |
| --- | --- | --- | --- |
| 1 | 11 | 12 | 크다 → r −1 |
| 1 | 8 | 9 | 작다 → l +1 |
| 2 | 8 | 10 | 찾음 |

### 합이 S 이상인 가장 짧은 연속 구간 (같은 방향)

`[2, 3, 1, 2, 4, 3]`, S = 7

| 구간 | 합 | 동작 | 최소 길이 |
| --- | --- | --- | --- |
| [2, 3, 1, 2] | 8 | ≥ 7 → 길이 4 기록, 왼쪽 줄임 | 4 |
| [3, 1, 2] | 6 | < 7 → 오른쪽 늘림 | 4 |
| [3, 1, 2, 4] | 10 | 길이 4, 왼쪽 줄임 | 4 |
| [1, 2, 4] | 7 | 길이 3, 왼쪽 줄임 | 3 |
| [2, 4] | 6 | 오른쪽 늘림 | 3 |
| [2, 4, 3] | 9 | 길이 3, 왼쪽 줄임 | 3 |
| [4, 3] | 7 | 길이 2, 왼쪽 줄임 | **2** |
| [3] | 3 | 끝 | 2 |

### 1차원 누적 합

`a = [3, 1, 4, 1, 5]` → `P = [0, 3, 4, 8, 9, 14]`
- `a[1] + a[2] + a[3]` = `P[4] − P[1]` = 9 − 3 = 6

### 2차원 누적 합

```
a          S (1-based)
1 2 3      1  3  6
4 5 6      5 12 21
7 8 9     12 27 45
```
- `S[2][2] = 5 + S[1][2] + S[2][1] − S[1][1] = 5 + 3 + 5 − 1 = 12`
- (2,2) ~ (3,3) 합 = `S[3][3] − S[1][3] − S[3][1] + S[1][1]` = 45 − 6 − 12 + 1 = **28** (5 + 6 + 8 + 9)

### 차분 배열

길이 5, `[1, 3]`에 +2, `[2, 4]`에 +3
- `D = [0, 2, 3, 0, −2, −3]` (인덱스 0~5)
- 누적: `[0, 2, 5, 5, 3]` (앞 5칸)

### 슬라이딩 윈도우 최댓값 (k = 3)

`[1, 3, −1, −3, 5, 3]`, 덱에는 인덱스, 값은 감소 순 유지

| i | 값 | 덱(값) | 윈도우 최댓값 |
| --- | --- | --- | --- |
| 0 | 1 | 1 | |
| 1 | 3 | 3 (1 제거) | |
| 2 | −1 | 3, −1 | 3 |
| 3 | −3 | 3, −1, −3 | 3 |
| 4 | 5 | 5 (5보다 작은 값 전부 제거) | 5 |
| 5 | 3 | 5, 3 | 5 |

## 4. 비교

| 기준 | 투 포인터 (양 끝) | 투 포인터 (같은 방향) | 이분 탐색 |
| --- | --- | --- | --- |
| 전제 | 정렬 | 구간 확장 시 단조 | 정렬 |
| 대상 | 두 원소 쌍 | 연속 구간 | 원소 하나 |
| 복잡도 | `O(n)` | `O(n)` | 원소마다 `O(log n)` |

| 기준 | 누적 합 | 슬라이딩 윈도우 |
| --- | --- | --- |
| 질의 | 임의 구간 여러 번 | 연속으로 이동하는 구간 |
| 메모리 | `O(n)` 배열 | `O(1)` |
| 음수 원소 | 상관없음 | 합 조건 투 포인터는 안 됨 |

## 5. Python 구현 / 라이브러리

- `itertools.accumulate(a, initial=0)` → 누적 합 (3.8+)

```python
from itertools import accumulate

a = [3, 1, 4, 1, 5]
P = list(accumulate(a, initial=0))      # [0, 3, 4, 8, 9, 14]
range_sum = lambda l, r: P[r + 1] - P[l]
```

```python
def min_len_subarray(a, S):
    l = cur = 0
    best = float('inf')
    for r, x in enumerate(a):
        cur += x
        while cur >= S:
            best = min(best, r - l + 1)
            cur -= a[l]
            l += 1
    return 0 if best == float('inf') else best
```

```python
def prefix_2d(a):
    n, m = len(a), len(a[0])
    S = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            S[i][j] = a[i-1][j-1] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]
    return S
```

```python
from collections import deque

def window_max(a, k):
    dq, res = deque(), []
    for i, x in enumerate(a):
        while dq and a[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(a[dq[0]])
    return res
```

```python
# 합이 K인 부분 배열 개수 (음수 포함 가능)
from collections import defaultdict

def count_subarrays(a, K):
    seen = defaultdict(int)
    seen[0] = 1
    cur = cnt = 0
    for x in a:
        cur += x
        cnt += seen[cur - K]
        seen[cur] += 1
    return cnt
```
