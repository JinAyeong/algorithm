# 동적 계획법

> 메모이제이션 vs 타뷸레이션, 최적 부분 구조, 냅색, LIS, LCS

## 1. 정의 / 핵심 성질

### 1.1 동적 계획법

#### 정의

큰 문제를 작은 부분 문제로 나누어 풀고, 각 부분 문제의 답을 저장해 두었다가 같은 부분 문제가 다시 나오면 저장된 답을 재사용하는 방법이다.

#### 등장 배경

피보나치 수를 재귀로 그대로 계산하면 같은 값을 반복해서 계산한다. 한 번 계산한 값을 저장해 두면 각 부분 문제를 한 번씩만 풀어 지수 시간을 다항 시간으로 줄일 수 있다.

#### 구조

```
fib(5)를 재귀로 계산할 때의 호출 트리
                    fib(5)
                 /          \
            fib(4)          fib(3)       ← fib(3)이 두 번
           /      \         /     \
       fib(3)   fib(2)   fib(2)  fib(1)  ← fib(2)가 세 번
       /    \
   fib(2) fib(1)

저장하면: fib(1) → fib(2) → fib(3) → fib(4) → fib(5), 각각 한 번씩
```

#### 성질

동적 계획법을 쓰려면 다음 두 조건이 필요하다.

| 조건 | 정의 | 설명 |
| --- | --- | --- |
| 최적 부분 구조 | 큰 문제의 최적해가 부분 문제의 최적해로 구성된다 | 그래야 저장해 둔 부분 문제의 답을 조합해 큰 문제의 답을 만들 수 있다 |
| 중복 부분 문제 | 같은 부분 문제가 여러 번 등장한다 | 중복이 없으면 저장해도 재사용할 일이 없다. 이 경우는 분할 정복이다 |

| 성질 | 설명 |
| --- | --- |
| 단순 재귀 피보나치는 `O(φⁿ) ≈ O(1.618ⁿ)`이다 | 호출 수가 피보나치 수처럼 늘어난다 |
| 동적 계획법 피보나치는 `O(n)`, 공간은 `O(1)`까지 줄일 수 있다 | fib(0)~fib(n)을 한 번씩 계산하고, 직전 두 값만 기억하면 된다 |
| 행렬 거듭제곱을 쓰면 피보나치는 `O(log n)`이다 | `[[1,1],[1,0]]ⁿ`을 분할 정복 거듭제곱으로 구한다 |
| 복잡도는 `상태 수 × 상태당 전이 비용`이다 | 모든 상태를 한 번씩 계산하고, 상태마다 참조하는 이전 상태 수만큼 일한다 |

### 1.2 구현 방식

| 방식 | 정의 | 특징 |
| --- | --- | --- |
| 메모이제이션 (top-down) | 재귀로 풀되, 계산한 결과를 저장하고 다시 호출되면 저장된 값을 반환한다 | 필요한 부분 문제만 계산한다. 재귀 깊이 제한과 함수 호출 비용이 있다 |
| 타뷸레이션 (bottom-up) | 가장 작은 부분 문제부터 표를 차례로 채운다 | 반복문이라 빠르고, 이전 행만 남기는 공간 최적화가 쉽다. 계산 순서를 직접 정해야 한다 |

### 1.3 설계 절차

1. **상태 정의**: `dp[i]`(또는 `dp[i][j]`)가 무엇을 뜻하는지 정한다. 가장 중요한 단계이다.
2. **점화식**: 한 상태를 더 작은 상태들로 나타낸다.
3. **초기값**: 더 이상 나눌 수 없는 가장 작은 상태의 값을 정한다.
4. **계산 순서**: 참조하는 상태가 먼저 계산되도록 순서를 정한다.
5. **답의 위치**: 표의 어느 칸이 최종 답인지 정한다.

### 1.4 대표 문제

| 문제 | 상태 | 점화식 | 복잡도 |
| --- | --- | --- | --- |
| 0/1 냅색 | `dp[i][w]`: 물건 1~i로 용량 w에서 얻는 최대 가치 | `max(dp[i−1][w], dp[i−1][w−wᵢ] + vᵢ)` | `O(nW)` |
| 무한 냅색 | `dp[w]`: 용량 w에서의 최대 가치 | `max(dp[w], dp[w−wᵢ] + vᵢ)` | `O(nW)` |
| LIS | `dp[i]`: i번째 원소로 끝나는 가장 긴 증가 수열의 길이 | `max(dp[j] + 1)` (j < i, aⱼ < aᵢ) | `O(n²)`, 이분 탐색으로 `O(n log n)` |
| LCS | `dp[i][j]`: X의 앞 i글자와 Y의 앞 j글자의 LCS 길이 | 같으면 `dp[i−1][j−1] + 1`, 다르면 `max(dp[i−1][j], dp[i][j−1])` | `O(nm)` |
| 편집 거리 | `dp[i][j]`: A의 앞 i글자를 B의 앞 j글자로 바꾸는 최소 연산 수 | 같으면 `dp[i−1][j−1]`, 다르면 `1 + min(삽입, 삭제, 교체)` | `O(nm)` |
| 동전 최소 개수 | `dp[x]`: 금액 x를 만드는 최소 동전 수 | `min(dp[x − c] + 1)` | `O(동전 수 × X)` |
| 동전 경우의 수 | `dp[x]`: 금액 x를 만드는 방법의 수 | `dp[x] += dp[x − c]` (동전을 바깥 반복) | `O(동전 수 × X)` |
| 행렬 연쇄 곱셈 | `dp[i][j]`: Aᵢ~Aⱼ를 곱하는 최소 곱셈 횟수 | `min(dp[i][k] + dp[k+1][j] + pᵢ₋₁·pₖ·pⱼ)` | `O(n³)` |
| 최적 BST | `cost[i][j]` | `min(cost[i][k−1] + cost[k+1][j]) + w(i, j)` | `O(n³)` |
| 플로이드-워셜 | `D[i][j]` (k단계) | `min(D[i][j], D[i][k] + D[k][j])` | `O(V³)` |

#### 대표 문제의 성질

| 성질 | 설명 |
| --- | --- |
| 0/1 냅색의 `O(nW)`는 의사 다항 시간이다 | W의 **값**에 비례하므로 입력 크기(W의 비트 수 `log W`)에 대해서는 지수이다. 0/1 냅색은 NP-완전이다 |
| 0/1 냅색을 1차원 배열로 풀 때는 w를 큰 쪽부터 돈다 | 작은 쪽부터 돌면 이번 물건으로 갱신된 값을 같은 반복에서 다시 써서 물건을 여러 번 넣게 된다 |
| 무한 냅색은 w를 작은 쪽부터 돈다 | 같은 물건을 여러 번 넣는 것이 허용된다 |
| 동전 경우의 수는 동전을 바깥 반복에 두면 조합, 금액을 바깥에 두면 순열을 센다 | 동전을 바깥에 두면 동전 사용 순서가 고정되어 `1+2`와 `2+1`이 한 번만 세어진다 |
| 행렬 연쇄 곱셈은 곱하는 순서에 따라 비용이 크게 다르다 | (p×q)와 (q×r) 행렬의 곱셈 비용은 `p·q·r`이고, 순서에 따라 중간 행렬의 크기가 달라진다 |

### 용어 정리

- **상태**: 부분 문제를 구분하는 값의 조합 (`dp`의 인덱스)
- **점화식**: 상태 간의 관계식
- **메모이제이션**: 계산한 결과를 저장해 재사용하는 것
- **LIS**: 가장 긴 증가하는 부분 수열 (Longest Increasing Subsequence)
- **LCS**: 가장 긴 공통 부분 수열 (Longest Common Subsequence). 부분 수열은 연속하지 않아도 된다
- **의사 다항 시간**: 입력값의 크기에는 다항이지만 입력의 비트 수에는 지수인 시간

## 2. 연산별 시간복잡도

- 일반식: `상태 수 × 상태당 전이 비용`
- 예: LCS 상태 `n·m`, 전이 `O(1)` → `O(nm)` / 행렬 연쇄 상태 `n²`, 전이 `O(n)` → `O(n³)`
- 공간 최적화: 이전 행만 참조하면 1차원 배열로 (`O(W)`, `O(m)`)
  - 0/1 냅색 1차원: w를 **큰 쪽부터** 순회 (같은 물건 중복 사용 방지)
  - 무한 냅색 1차원: w를 **작은 쪽부터** 순회 (중복 사용 허용)

## 3. 동작 과정

### 0/1 냅색

용량 W = 5, 물건 `(무게, 가치)`: ① (2, 3), ② (3, 4), ③ (4, 5), ④ (5, 6)

| i \ w | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| ① (2, 3) | 0 | 0 | 3 | 3 | 3 | 3 |
| ② (3, 4) | 0 | 0 | 3 | 4 | 4 | 7 |
| ③ (4, 5) | 0 | 0 | 3 | 4 | 5 | 7 |
| ④ (5, 6) | 0 | 0 | 3 | 4 | 5 | 7 |

- `dp[2][5] = max(dp[1][5], dp[1][2] + 4) = max(3, 7) = 7`
- 답 7 (① + ②). 역추적: `dp[4][5] = dp[3][5] = dp[2][5]` → ②를 넣음 → `dp[1][2] = 3` → ①을 넣음

### LCS

X = `ABCB`, Y = `BDCB`

| | | B | D | C | B |
| --- | --- | --- | --- | --- | --- |
| | 0 | 0 | 0 | 0 | 0 |
| A | 0 | 0 | 0 | 0 | 0 |
| B | 0 | **1** | 1 | 1 | 1 |
| C | 0 | 1 | 1 | **2** | 2 |
| B | 0 | 1 | 1 | 2 | **3** |

- 길이 3, LCS `BCB` (대각선으로 증가한 칸을 역추적)

### LIS

`[10, 20, 10, 30, 20, 50]`

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| a | 10 | 20 | 10 | 30 | 20 | 50 |
| dp | 1 | 2 | 1 | 3 | 2 | 4 |

- 답 4 (`10, 20, 30, 50`)

`O(n log n)` 방식: 길이 k인 증가 수열의 마지막 값 최솟값을 `tails`에 유지, 각 원소를 `bisect_left` 위치에 덮어씀
- 10 → `[10]`, 20 → `[10, 20]`, 10 → `[10, 20]`, 30 → `[10, 20, 30]`, 20 → `[10, 20, 30]`, 50 → `[10, 20, 30, 50]` → 길이 4
- `tails`는 실제 LIS가 아님 (길이만 맞음)

### 행렬 연쇄 곱셈

A1 (10×30), A2 (30×5), A3 (5×60)
- `(A1·A2)·A3` = `10·30·5 + 10·5·60` = 1500 + 3000 = **4500**
- `A1·(A2·A3)` = `30·5·60 + 10·30·60` = 9000 + 18000 = 27000
- 곱하는 순서에 따라 6배 차이. (p×q)와 (q×r) 곱셈 비용은 `p·q·r`

### 동전 경우의 수 vs 순서 있는 경우의 수

동전 {1, 2}, 금액 3
- 동전을 바깥 반복 → 조합: `{1,1,1}, {1,2}` → 2가지
- 금액을 바깥 반복 → 순열: `1+1+1, 1+2, 2+1` → 3가지

## 4. 비교

| 기준 | DP | 분할 정복 | 그리디 |

| 예 | 냅색, LCS, 플로이드 | 병합 정렬, 퀵 정렬 | 활동 선택, 크루스칼, 다익스트라 |

## 5. Python 구현 / 라이브러리

```python
from functools import lru_cache   # 3.9+는 functools.cache

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

```python
def knapsack(W, items):            # items: [(w, v), ...]
    dp = [0] * (W + 1)
    for w, v in items:
        for c in range(W, w - 1, -1):    # 큰 쪽부터 → 0/1
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[W]
```

```python
def lcs(x, y):
    n, m = len(x), len(y)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if x[i - 1] == y[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[n][m]
```

```python
from bisect import bisect_left

def lis(a):
    tails = []
    for x in a:
        i = bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
```

```python
def edit_distance(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[n][m]
```
