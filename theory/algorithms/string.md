# 문자열 패턴 매칭

> 단순 매칭, KMP(실패 함수 계산), 보이어-무어, 라빈-카프

## 1. 정의 / 핵심 성질

### 1.1 문자열 패턴 매칭

#### 정의

길이 n인 텍스트 T에서 길이 m인 패턴 P가 나타나는 위치를 모두 찾는 문제이다.

#### 등장 배경

문서 편집기의 찾기, 검색 엔진, DNA 서열 분석처럼 긴 텍스트에서 특정 문자열을 찾는 일이 많다. 모든 위치에서 처음부터 비교하면 최악 `O(nm)`이 걸려, 이미 비교한 정보를 재활용하는 알고리즘들이 고안되었다.

### 1.2 단순 매칭 (brute force)

#### 정의

텍스트의 모든 시작 위치(`n − m + 1`개)에서 패턴을 앞부터 한 글자씩 비교하고, 불일치하면 시작 위치를 한 칸 옮겨 처음부터 다시 비교하는 방법이다.

#### 구조

```
T: A A A A A B
P: A A B            ← 3번째 글자에서 불일치
     A A B          ← 한 칸 밀고 처음부터 다시
       A A B
         A A B      ← 일치
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 최악 `O(nm)`이다 | `T = AAA…AB`, `P = AA…AB`처럼 매번 패턴 끝에서 불일치하면 위치마다 m번 비교한다 |
| 무작위 텍스트에서는 평균 `O(n)`에 가깝다 | 대부분 첫 한두 글자에서 불일치한다 |
| 이미 일치한 정보를 버린다 | 불일치하면 텍스트 위치를 되돌려 다시 비교한다 |

### 1.3 KMP 알고리즘

#### 정의

불일치가 일어났을 때 이미 일치한 부분의 정보(실패 함수)를 이용해 패턴을 한 번에 여러 칸 밀고, 텍스트의 비교 위치는 되돌리지 않는 문자열 매칭 알고리즘이다.

#### 실패 함수

`pi[j]`는 패턴의 앞 j+1글자 `P[0..j]`에서 **접두사이면서 동시에 접미사인 가장 긴 문자열의 길이**이다(자기 자신은 제외).

```
P = A B A B A C A
j = 0 1 2 3 4 5 6
pi= 0 0 1 2 3 0 1

j = 4: "ABABA" → 접두사 "ABA" = 접미사 "ABA" → 3
```

교재(Horowitz 등)에서는 같은 개념을 "일치하는 접두사의 마지막 인덱스"로 정의하여 값이 `pi − 1`(없으면 −1)이다.

#### 구조

```
T: A B A B A B A C A
P: A B A B A C           ← T[5]='B'와 P[5]='C' 불일치
                            이미 일치한 "ABABA"의 접두사=접미사 "ABA"(pi[4]=3)
       A B A B A C A     ← 패턴을 2칸 밀고, P[3]부터 비교를 이어간다
                            T의 비교 위치는 그대로
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 불일치 시 `j = pi[j − 1]`로 이동해 비교를 이어간다 | 일치한 부분의 접미사가 패턴의 접두사와 같으므로 그만큼은 다시 비교할 필요가 없다 |
| 텍스트 포인터는 뒤로 가지 않는다 | 이미 본 텍스트의 정보가 실패 함수에 담겨 있다. 스트림 데이터에도 쓸 수 있다 |
| 매칭은 `O(n)`이다 | 텍스트 포인터는 n번 전진하고, j가 줄어드는 횟수는 늘어난 횟수(최대 n)를 넘지 못한다 |
| 실패 함수 계산은 `O(m)`이다 | 패턴을 자기 자신과 매칭하는 것과 같은 원리이다 |
| 전체 `O(n + m)`이 최악에도 보장된다 | 위 두 단계의 합이다 |

### 1.4 보이어-무어 알고리즘

#### 정의

패턴을 **오른쪽에서 왼쪽으로** 비교하고, 불일치가 나면 두 가지 규칙 중 더 멀리 이동하는 쪽으로 패턴을 미는 문자열 매칭 알고리즘이다.
- 나쁜 문자 규칙(bad character): 불일치한 텍스트 문자가 패턴에서 마지막으로 나오는 위치에 맞춰 민다. 패턴에 없는 문자면 그 문자를 통째로 건너뛴다.
- 좋은 접미사 규칙(good suffix): 이미 일치한 접미사가 패턴의 다른 위치에도 있으면 그 위치에 맞춰 민다.

#### 구조

```
T: H E R E   I S   A   S I M P L E
P: E X A M P L E
               ↑ 오른쪽 끝부터 비교: 'S' ≠ 'E'
                 'S'는 패턴에 없음 → 패턴 길이(7)만큼 건너뜀
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 최선 `O(n/m)`으로 텍스트 일부를 아예 보지 않는다 | 패턴에 없는 문자를 만나면 패턴 길이만큼 건너뛴다 |
| 패턴이 길고 알파벳이 클수록 빠르다 | 패턴에 없는 문자를 만날 확률이 높아져 멀리 건너뛴다 |
| 기본형의 최악은 `O(nm)`이다 | 반복 문자로 된 텍스트에서 이동이 작다. 갈릴 규칙(Galil rule)을 더하면 `O(n + m)`이다 |
| 호스풀(Horspool)은 나쁜 문자 규칙만 쓰는 단순화 버전이다 | 비교한 창의 마지막 문자 기준으로 `shift[c] = m − 1 − (P[0..m−2]에서 c의 마지막 위치)`만큼 민다. 없으면 m |

### 1.5 라빈-카프 알고리즘

#### 정의

문자열을 수로 보고 해시값을 구해, 텍스트의 각 위치에서 길이 m인 부분 문자열의 해시값이 패턴의 해시값과 같을 때만 실제로 문자를 비교하는 알고리즘이다.

#### 구조

```
d = 10 (진법), q = 13 (나머지)
T = 2 3 5 9 0 2 ...,  m = 3

"235" → 235 mod 13 = 1
"359" → (235 − 2·100)·10 + 9 = 359 → 359 mod 13 = 8     ← 앞 글자 빼고 뒷 글자 더함
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 다음 위치의 해시를 `O(1)`에 구한다 (롤링 해시) | `h' = ((h − T[i]·d^(m−1))·d + T[i+m]) mod q`로 맨 앞 글자를 빼고 새 글자를 더한다 |
| 해시가 같아도 실제로 같은 문자열인지 확인해야 한다 | 서로 다른 문자열이 같은 해시값을 가질 수 있다(가짜 일치, spurious hit) |
| 평균 `O(n + m)`, 최악 `O(nm)`이다 | 가짜 일치가 많으면 매번 m글자를 비교한다. q를 큰 소수로 하면 가짜 일치가 드물다 |
| 여러 패턴을 동시에 찾을 때 유리하다 | 패턴들의 해시값을 집합에 넣어 두고 한 번 훑으며 확인한다. 2차원 패턴 매칭으로도 확장된다 |

### 용어 정리

- **텍스트 / 패턴**: 검색 대상 문자열 / 찾을 문자열
- **접두사 / 접미사**: 문자열의 앞부분 / 뒷부분
- **실패 함수 (접두사 함수)**: 각 위치까지의 접두사=접미사 최대 길이를 저장한 표
- **롤링 해시**: 이전 해시값에서 한 글자를 빼고 더해 다음 해시값을 구하는 방법
- **가짜 일치 (spurious hit)**: 해시값은 같지만 실제 문자열은 다른 경우
- **σ**: 알파벳(문자 종류)의 크기

## 2. 연산별 시간복잡도

| 알고리즘 | 전처리 | 매칭 (평균) | 매칭 (최악) | 비고 |
| --- | --- | --- | --- | --- |
| 단순 매칭 | 없음 | `O(n)` 근처 | `O(nm)` | 구현 단순 |
| KMP | `O(m)` | `O(n)` | `O(n)` | 텍스트 포인터 후진 없음 → 스트림 처리 가능 |
| 보이어-무어 | `O(m + σ)` | `O(n/m)` ~ `O(n)` | `O(nm)` (기본형) | 실제로 가장 빠른 편, 긴 패턴 |
| 라빈-카프 | `O(m)` | `O(n + m)` | `O(nm)` | 다중 패턴 |

σ: 알파벳 크기

## 3. 동작 과정

### 실패 함수 계산

P = `ABABACA`

| j | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| P[j] | A | B | A | B | A | C | A |
| pi[j] | 0 | 0 | 1 | 2 | 3 | 0 | 1 |
| 교재식 f(j) | −1 | −1 | 0 | 1 | 2 | −1 | 0 |

- j = 4: `ABABA`의 접두사=접미사 최장은 `ABA` → 3
- j = 5: `ABABAC`는 C로 끝나는데 접두사는 A로 시작 → 0
- j = 6: `ABABACA` → `A` → 1

계산 방법 (j는 현재까지 일치한 길이)
- `i = 1`부터, `P[i] == P[j]`면 `j += 1`, `pi[i] = j`
- 다르면 `j > 0`인 동안 `j = pi[j − 1]`로 줄이며 다시 비교

다른 예: `AABAA` → `[0, 1, 0, 1, 2]`, `AAAA` → `[0, 1, 2, 3]`, `ABCDABD` → `[0, 0, 0, 0, 1, 2, 0]`

### KMP 매칭

T = `ABABABACA`, P = `ABABACA`

| T 위치 i | T[i] | 비교 P[j] | 결과 | j |
| --- | --- | --- | --- | --- |
| 0~4 | A B A B A | P[0..4] | 일치 | 5 |
| 5 | B | P[5] = C | 불일치 → `j = pi[4] = 3` | 3 |
| 5 | B | P[3] = B | 일치 | 4 |
| 6 | A | P[4] = A | 일치 | 5 |
| 7 | C | P[5] = C | 일치 | 6 |
| 8 | A | P[6] = A | 일치 → 완성 | 7 |

- 시작 위치 `8 − 7 + 1 = 2`에서 발견
- i는 한 번도 뒤로 가지 않음. 불일치 후 이미 맞은 `ABA`를 다시 비교하지 않음

### 호스풀 이동표

P = `ABAC` (m = 4), `P[0..2]` = `ABA`에서 마지막 등장 인덱스: A → 2, B → 1

| 문자 | A | B | C | 그 외 |
| --- | --- | --- | --- | --- |
| 이동량 | 4 − 1 − 2 = 1 | 4 − 1 − 1 = 2 | 4 | 4 |

- 창의 마지막 문자가 패턴에 없는 문자면 4칸(패턴 길이) 통째로 점프

### 라빈-카프 롤링 해시

d = 10, q = 13, T = `23590`, m = 3
- `h("235") = 235 mod 13 = 1`
- 다음 창 `"359"`: `((1 − 2 · (100 mod 13)) · 10 + 9) mod 13 = ((1 − 18) · 10 + 9) mod 13 = −161 mod 13 = 8`
- 확인: `359 mod 13 = 8`
- 패턴 해시와 같은 창만 실제 비교

## 5. Python 구현 / 라이브러리

- `P in T`, `T.find(P)`, `T.index(P)`, `T.count(P)`: C로 구현된 빠른 검색 (보이어-무어-호스풀 계열 변형, 3.10부터 긴 패턴은 Two-Way 알고리즘)
- 정규식: `re.finditer`

```python
def failure(p):
    pi = [0] * len(p)
    j = 0
    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
            pi[i] = j
    return pi


def kmp(t, p):
    pi, res, j = failure(p), [], 0
    for i, ch in enumerate(t):
        while j > 0 and ch != p[j]:
            j = pi[j - 1]
        if ch == p[j]:
            j += 1
            if j == len(p):
                res.append(i - len(p) + 1)
                j = pi[j - 1]
    return res

kmp("ABABABACA", "ABABACA")   # [2]
```

```python
def rabin_karp(t, p, d=256, q=10**9 + 7):
    n, m = len(t), len(p)
    if m > n:
        return []
    high = pow(d, m - 1, q)
    hp = ht = 0
    for i in range(m):
        hp = (hp * d + ord(p[i])) % q
        ht = (ht * d + ord(t[i])) % q
    res = []
    for i in range(n - m + 1):
        if hp == ht and t[i:i + m] == p:
            res.append(i)
        if i < n - m:
            ht = ((ht - ord(t[i]) * high) * d + ord(t[i + m])) % q
    return res
```
