# 트리

> 용어, 이진 트리 성질(노드 수·높이·리프 수 공식), 포화/완전 이진 트리, 순회(전위·중위·후위·레벨), 부모·자식 배열 표현, 순회 결과로 트리 복원, 스레드 이진 트리, 수식 트리, 일반 트리 → 이진 트리 변환, 트라이

## 1. 정의 / 핵심 성질

### 1.1 트리

#### 정의

하나의 루트 노드와, 루트 아래에 서로 겹치지 않는 하위 트리(서브트리)들로 이루어진 계층적 자료구조이다. 사이클이 없다.

#### 등장 배경

배열·리스트 같은 선형 구조로는 조직도, 폴더 구조, 수식처럼 위아래가 있는 계층 관계를 표현하기 어렵다. 트리는 이런 관계를 그대로 표현하고, 탐색 범위를 단계마다 좁힐 수 있어 선형 구조보다 빠른 탐색이 가능하다.

#### 구조

```
레벨 1             A             ← 루트 (부모가 없는 노드)
                /  |  \
레벨 2         B   C   D         ← B, C, D는 형제 (부모가 같음)
              / \       \
레벨 3       E   F       G       ← 리프: E, F, C, G (자식이 없는 노드)
```

- A의 차수는 3, B의 차수는 2, 트리의 차수는 3이다
- 트리의 높이는 3이다
- B, E, F는 A의 서브트리 중 하나이다

#### 성질

| 성질 | 설명 |
| --- | --- |
| 노드가 n개이면 간선은 `n − 1`개이다 | 루트를 제외한 모든 노드가 부모로 가는 간선을 정확히 1개 가진다 |
| 두 노드 사이의 경로는 유일하다 | 경로가 두 개면 사이클이 생긴다 |
| 루트를 제거하면 포리스트가 된다 | 각 서브트리가 독립된 트리로 남는다 |

### 1.2 이진 트리

#### 정의

모든 노드의 자식이 최대 2개이고, 왼쪽 자식과 오른쪽 자식을 구분하는 트리이다. 공집합(노드 0개)도 이진 트리로 본다.

#### 구조

```
      A              A
     /                \
    B                  B
서로 다른 이진 트리 (왼쪽 자식인지 오른쪽 자식인지 구분)
```

#### 성질

루트의 레벨을 1로 보는 교재(전공 교재)와 0으로 보는 교재(코딩 테스트 자료)가 있다. 레벨 0 기준에서는 높이를 "루트에서 가장 먼 노드까지의 간선 수"로 정의한다. **시험에서는 문제의 조건을 먼저 확인한다.**

| 성질 | 레벨 1 기준 | 레벨 0 기준 | 설명 |
| --- | --- | --- | --- |
| 레벨 i의 최대 노드 수 | `2^(i−1)` | `2^i` | 레벨이 내려갈 때마다 최대 2배가 된다 |
| 높이 h의 최대 노드 수 | `2^h − 1` | `2^(h+1) − 1` | 각 레벨의 최대 노드 수를 모두 더한다 |
| 높이 h의 최소 노드 수 | `h` | `h + 1` | 레벨마다 노드가 1개씩인 편향 트리 |
| 높이 h인 완전 이진 트리의 노드 수 범위 | `2^(h−1) ≤ n ≤ 2^h − 1` | `2^h ≤ n ≤ 2^(h+1) − 1` | 마지막 레벨에 1개만 있을 때가 최소, 꽉 찼을 때가 최대 |
| 노드 n개의 최소 높이 | `⌈log₂(n+1)⌉` | `⌈log₂(n+1)⌉ − 1` | 높이 h에 담을 수 있는 최대 노드 수가 n 이상이어야 한다 |
| 높이 3인 포화 이진 트리의 노드 수 | 7 | 15 | 위 공식에 h = 3 대입 |

아래 공식은 레벨 기준과 관계없이 같다.

| 성질 | 공식 | 설명 |
| --- | --- | --- |
| 리프 수와 차수 2인 노드 수의 관계 | `n0 = n2 + 1` | 아래 증명 |
| 노드 n개 연결 표현의 null 링크 수 | `n + 1` | 링크는 `2n`개인데 실제로 쓰는 링크(간선)는 `n − 1`개 |
| 노드 n개로 만들 수 있는 서로 다른 이진 트리 수 | 카탈란 수 `C(n)` (n=3 → 5, n=4 → 14) | 왼쪽에 i개, 오른쪽에 `n−1−i`개를 두는 경우를 모두 더한다 |

`n0 = n2 + 1`의 증명
- 노드 수로 세면 `n = n0 + n1 + n2`이다.
- 간선 수로 세면 `n − 1 = n1 + 2·n2`이다. (차수 1인 노드는 간선 1개, 차수 2인 노드는 2개를 내린다)
- 두 식을 빼면 `1 = n0 − n2`, 즉 `n0 = n2 + 1`이다.
- 일반 트리로 확장하면 차수 m 트리에서 `n0 = 1 + n2 + 2·n3 + … + (m−1)·nm`이다.

### 1.3 이진 트리의 종류

#### 구조

```
포화 이진 트리       완전 이진 트리       편향 이진 트리
       1                   1               1
     /   \               /   \              \
    2     3             2     3              2
   / \   / \           / \                    \
  4   5 6   7         4   5                    3
```

#### 정의

| 종류 | 정의 |
| --- | --- |
| 포화 이진 트리 (full) | 모든 레벨이 꽉 찬 이진 트리. 높이 k이면 노드가 정확히 `2^k − 1`개이다 |
| 완전 이진 트리 (complete) | 마지막 레벨을 제외하고 모두 차 있으며, 마지막 레벨은 왼쪽부터 빈틈없이 채운 이진 트리이다 |
| 정 이진 트리 (proper, strict) | 모든 노드의 자식이 0개 또는 2개인 이진 트리이다 |
| 편향 이진 트리 (skewed) | 모든 노드가 한쪽 방향 자식만 가진 이진 트리이다 |

- 영어 "full binary tree"를 정 이진 트리의 의미로 쓰는 교재도 있다. 한국 교재에서 "포화 이진 트리"는 위 표의 첫 번째 정의이다.
- 포화 이진 트리는 항상 완전 이진 트리이지만, 그 역은 성립하지 않는다.

#### 완전 이진 트리의 성질 (노드 n개, 1번부터 번호)

| 성질 | 설명 |
| --- | --- |
| 높이는 `⌊log₂ n⌋ + 1`이다 | 마지막 레벨 전까지 꽉 차 있다 |
| 마지막 내부 노드는 `⌊n/2⌋`번이다 | 마지막 노드 n의 부모이다 |
| 리프는 `⌈n/2⌉`개, 내부 노드는 `⌊n/2⌋`개이다 | `⌊n/2⌋`번 이후는 모두 리프이다 |
| 차수 1인 노드는 0개 또는 1개이다 | 왼쪽부터 채우므로 자식이 하나뿐인 노드는 마지막 내부 노드뿐이다 |

### 1.4 이진 트리의 표현

#### 배열 표현

노드에 위에서 아래로, 왼쪽에서 오른쪽으로 번호를 매겨 그 번호를 인덱스로 사용한다.

```
       A(1)
      /    \
   B(2)    C(3)        배열: [ _, A, B, C, D, _, _, E ]
   /          \                  1  2  3  4  5  6  7
 D(4)        E(7)
```

| 성질 | 설명 |
| --- | --- |
| 노드 i의 부모는 `i // 2`, 왼쪽 자식은 `2i`, 오른쪽 자식은 `2i + 1`이다 | 레벨마다 번호가 2배씩 늘어난다 |
| 완전 이진 트리는 공간 낭비가 없다 | 번호가 1부터 n까지 빈틈없이 채워진다 |
| 높이 k 편향 트리는 노드 k개에 `2^k − 1`칸이 필요하다 | 빈 위치도 번호를 차지한다 |

#### 연결 표현

각 노드를 `[왼쪽 링크 | 데이터 | 오른쪽 링크]` 형태로 만들어 포인터로 연결한다. 모양과 관계없이 노드 n개만큼만 공간을 쓰지만, 부모를 찾으려면 부모 링크를 따로 두어야 한다.

#### 부모·자식 배열 표현

노드 번호를 인덱스로 하는 배열 세 개에 연결 관계를 저장한다. 코딩 테스트에서 "부모 자식" 쌍으로 간선이 주어질 때 주로 쓴다.
- `left[p]`: 노드 p의 왼쪽 자식 번호 (없으면 0)
- `right[p]`: 노드 p의 오른쪽 자식 번호
- `par[c]`: 노드 c의 부모 번호 (루트는 0)

```
       1              left  = [_, 2, 4, 0, 0]
      / \             right = [_, 3, 0, 0, 0]
     2   3            par   = [_, 0, 1, 1, 2]
    /                          0  1  2  3  4  (인덱스 = 노드 번호)
   4
```

| 성질 | 설명 |
| --- | --- |
| 부모와 자식 모두 `O(1)`에 찾는다 | 두 방향을 각각 배열로 저장한다 |
| 루트는 `par`가 0인 노드이다 | 아무 노드에서 `par`를 따라 올라가 더 이상 부모가 없으면 루트이다 |
| 서브트리 크기는 재귀로 구한다 | `size(v) = size(left[v]) + size(right[v]) + 1`, `size(0) = 0` |
| 공간은 노드 수에 비례한다 | 편향 트리여도 배열 표현처럼 낭비가 생기지 않는다 |

### 1.5 일반 트리의 이진 트리 변환

#### 정의

자식 수가 제각각인 일반 트리를 "왼쪽 자식-오른쪽 형제(left child-right sibling)" 규칙으로 이진 트리로 바꾸는 방법이다.
- 각 노드의 첫 번째 자식을 왼쪽 링크로 연결한다.
- 바로 다음 형제를 오른쪽 링크로 연결한다.

#### 등장 배경

일반 트리는 노드마다 자식 수가 달라 링크 개수를 정하기 어렵다. 이진 트리로 바꾸면 모든 노드를 같은 형태(링크 2개)로 표현할 수 있다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 변환된 이진 트리의 루트는 오른쪽 자식이 없다 | 일반 트리의 루트는 형제가 없다 |
| 포리스트도 변환할 수 있다 | 각 트리를 변환한 뒤 루트끼리를 오른쪽 링크(형제)로 연결한다 |

### 1.6 스레드 이진 트리

#### 정의

null 링크 자리에 중위 순회의 선행자 또는 후속자를 가리키는 포인터(스레드)를 넣은 이진 트리이다.
- 왼쪽 링크가 null이면 → 중위 순회에서 바로 앞 노드(선행자)를 가리킨다.
- 오른쪽 링크가 null이면 → 중위 순회에서 바로 다음 노드(후속자)를 가리킨다.

#### 등장 배경

노드 n개인 이진 트리에는 null 링크가 `n + 1`개나 있어 공간이 낭비된다. 또 중위 순회를 하려면 스택이나 재귀가 필요하다. 이 null 링크를 순회 정보로 활용하면 두 문제를 함께 해결할 수 있다.

#### 구조

```
        A            중위 순회: B → A → C
       / \
      B   C          B의 오른쪽 null → A (후속자)
                     C의 왼쪽 null → A (선행자)
                     B의 왼쪽, C의 오른쪽 → 헤드 노드
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 링크가 실제 자식인지 스레드인지 구분하는 플래그가 필요하다 | 같은 포인터 칸을 두 용도로 쓴다 |
| 스택 없이 중위 순회가 가능하다 | 스레드를 따라가면 다음 노드로 바로 이동한다 |
| 삽입·삭제가 복잡해진다 | 주변 노드의 스레드도 함께 고쳐야 한다 |

### 1.7 수식 트리

#### 정의

내부 노드에 연산자, 리프에 피연산자를 두어 수식을 표현한 이진 트리이다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 전위 순회 결과는 전위 표기식, 후위 순회 결과는 후위 표기식이다 | 연산자(루트)를 피연산자(서브트리)보다 먼저 / 나중에 방문한다 |
| 중위 순회는 중위 표기식이 되지만 괄호를 넣어야 한다 | 트리 모양에 담긴 계산 순서가 중위 표기에서는 드러나지 않는다 |
| 후위 표기식으로 쉽게 만들 수 있다 | 피연산자는 노드로 만들어 push, 연산자는 2개를 pop 해 자식으로 붙인 뒤 push 한다 (먼저 꺼낸 것이 오른쪽) |

### 1.8 트라이 (Trie)

#### 정의

문자열을 문자 단위로 나누어, 루트에서 내려가는 경로로 저장하는 트리이다. 접두사 트리(prefix tree)라고도 한다.

#### 등장 배경

문자열을 BST에 저장하면 비교 한 번에 문자열 길이만큼 시간이 들어 탐색이 `O(L log n)`이 된다. 트라이는 문자 하나씩 따라 내려가므로 저장된 단어 수와 관계없이 `O(L)`에 탐색하고, 접두사 검색도 자연스럽게 지원한다.

#### 구조

```
          (루트)
          /    \
         a      b
         |      |
         p      e
         |      |
         p*     e*         * : 단어의 끝
         |
         l
         |
         e*
저장된 단어: app, apple, bee
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 길이 L 문자열의 삽입·탐색이 `O(L)`이다 | 문자 하나당 한 레벨씩 내려간다 |
| 공통 접두사는 경로를 공유한다 | app와 apple은 `a → p → p`까지 같은 노드를 쓴다 |
| 단어 끝 표시가 필요하다 | 없으면 apple만 저장했을 때 app도 있는 것으로 오인한다 |
| 메모리를 많이 쓴다 | 노드마다 알파벳 크기만큼 자식 칸을 둘 수 있다 |

### 용어 정리

- **노드의 차수**: 그 노드의 자식 수
- **트리의 차수**: 노드 차수 중 최댓값
- **리프(단말 노드)**: 자식이 없는 노드. 나머지는 내부(비단말) 노드
- **레벨**: 루트를 1(또는 0)로 시작해 아래로 1씩 증가하는 층 번호
- **높이(깊이)**: 트리의 최대 레벨
- **형제**: 부모가 같은 노드
- **조상 / 자손**: 루트까지 가는 경로상의 노드 / 서브트리에 속한 노드
- **서브트리**: 어떤 노드와 그 자손으로 이루어진 트리
- **포리스트**: 서로 겹치지 않는 트리들의 집합
- **순회**: 트리의 모든 노드를 한 번씩 방문하는 것

## 2. 연산별 시간복잡도

| 연산 | 복잡도 |
| --- | --- |
| 순회 (전위/중위/후위/레벨) | `O(n)` 시간, 재귀 스택 `O(h)` 공간 (레벨 순회는 큐 `O(n)`) |
| 배열 표현 부모/자식 접근 | `O(1)` |
| 연결 표현 부모 찾기 | `O(n)` (parent 링크 없을 때) |
| 높이·노드 수 계산 | `O(n)` |
| 전위+중위로 복원 | `O(n²)` 단순, 중위 인덱스를 해시에 저장하면 `O(n)` |
| 스레드 이진 트리 중위 순회 | `O(n)` 시간, `O(1)` 추가 공간 |
| 트라이 삽입/탐색 | `O(L)` |

## 3. 동작 과정

### 순회

```
        A
      /   \
     B     C
    / \     \
   D   E     F
      /
     G
```

| 순회 | 방문 순서 | 결과 |
| --- | --- | --- |
| 전위 (preorder) | 루트 → 왼쪽 → 오른쪽 | A B D E G C F |
| 중위 (inorder) | 왼쪽 → 루트 → 오른쪽 | D B G E A C F |
| 후위 (postorder) | 왼쪽 → 오른쪽 → 루트 | D G E B F C A |
| 레벨 (level-order) | 위에서 아래, 왼쪽에서 오른쪽 | A B C D E F G |

- 전위의 첫 원소 = 루트, 후위의 마지막 원소 = 루트

### 순회 결과로 트리 복원

| 주어진 순회 | 복원 가능 여부 |
| --- | --- |
| 전위 + 중위 | 유일하게 복원 |
| 후위 + 중위 | 유일하게 복원 |
| 레벨 + 중위 | 유일하게 복원 |
| 전위 + 후위 | 일반적으로 불가 (자식이 하나일 때 왼쪽/오른쪽 구분 불가). 정 이진 트리면 가능 |

전위 `A B D E G C F`, 중위 `D B G E A C F`
1. 전위 첫 원소 A = 루트. 중위에서 A 기준 왼쪽 `D B G E`, 오른쪽 `C F`
2. 왼쪽 서브트리: 전위에서 다음 원소 B가 루트. 중위 `D | B | G E` → 왼쪽 D, 오른쪽 `G E`
3. `G E`: 전위 순서상 E가 먼저 → E가 루트, 중위 `G E` → G는 E의 왼쪽
4. 오른쪽 서브트리: 전위 `C F` → C 루트, 중위 `C F` → F는 C의 오른쪽

### 수식 트리

`(A + B) * C − D`

```
          −
        /   \
       *     D
      / \
     +   C
    / \
   A   B
```
- 전위: `− * + A B C D`
- 후위: `A B + C * D −`

### 개수 계산 예

- 리프 10개, 차수 1 노드 5개인 이진 트리의 전체 노드 수: `n2 = 10 − 1 = 9` → `10 + 5 + 9 = 24`
- 노드 100개 완전 이진 트리: 높이 `⌊log₂100⌋ + 1 = 7`, 리프 `50`, 마지막 내부 노드 인덱스 `50`
- 높이 5 포화 이진 트리: 노드 `31`, 리프 `16`
- 노드 3개 이진 트리 모양: 5가지

### 일반 트리 → 이진 트리

```
일반 트리                 이진 트리 (왼쪽=첫 자식, 오른쪽=다음 형제)
      A                         A
    / | \                      /
   B  C  D                    B
  / \    |                  /   \
 E   F   G                 E     C
                            \     \
                             F     D
                                  /
                                 G
```

### 스레드 이진 트리 중위 후속자 찾기

- 노드 x의 오른쪽이 스레드면 → 그 스레드가 후속자
- 아니면 → 오른쪽 자식으로 한 번 간 뒤 왼쪽 끝까지 내려간 노드가 후속자

## 4. 비교

| 순회 | 주 용도 |
| --- | --- |
| 전위 | 트리 복사, 직렬화, 디렉터리 구조 출력 |
| 중위 | BST 정렬 순서 출력, 수식의 중위 표기 |
| 후위 | 트리 삭제(자식 먼저 해제), 디렉터리 용량 계산, 후위 표기 계산 |
| 레벨 | 루트로부터 최단 거리, 너비 계산 |

| 표현 | 장점 | 단점 |
| --- | --- | --- |
| 배열 | 부모·자식 인덱스 계산 `O(1)`, 링크 공간 없음 | 편향 트리면 공간 낭비, 크기 고정 |
| 연결 | 모양과 무관하게 n개 노드만 사용, 삽입·삭제 유연 | 링크 공간, 부모 접근 어려움 |

| 구분 | 이진 트리 | 트라이 | 해시 (문자열 키) |
| --- | --- | --- | --- |
| 정확 탐색 | BST 기준 `O(L log n)` | `O(L)` | 평균 `O(L)` |
| 접두사 탐색 | 어려움 | 쉬움 | 불가 |
| 공간 | 작음 | 큼 | 중간 |

```python
class Node:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right


def preorder(n):
    if n:
        print(n.val); preorder(n.left); preorder(n.right)

def inorder(n):
    if n:
        inorder(n.left); print(n.val); inorder(n.right)

def postorder(n):
    if n:
        postorder(n.left); postorder(n.right); print(n.val)
```

from collections import deque

def level_order(root):
    q = deque([root])
    while q:
        n = q.popleft()
        print(n.val)
        if n.left: q.append(n.left)
        if n.right: q.append(n.right)


def inorder_iter(root):
    st, cur = [], root
    while st or cur:
        while cur:
            st.append(cur)
            cur = cur.left
        cur = st.pop()
        print(cur.val)
        cur = cur.right
```

# 전위 + 중위 → 후위 출력
def build(pre, ino):
    if not pre:
        return []
    root = pre[0]
    k = ino.index(root)
    return build(pre[1:k+1], ino[:k]) + build(pre[k+1:], ino[k+1:]) + [root]
```

```python
# 트라이
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        cur = self.root
        for ch in word:
            cur = cur.setdefault(ch, {})
        cur['$'] = True

    def search(self, word):
        cur = self.root
        for ch in word:
            if ch not in cur:
                return False
            cur = cur[ch]
        return '$' in cur
```
