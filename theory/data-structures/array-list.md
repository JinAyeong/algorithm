# 배열 · 연결 리스트

> 배열, 다차원 배열 주소 계산(행 우선·열 우선), 희소 행렬, 다항식 표현, 단일/이중/원형 연결 리스트, 동적 배열

## 1. 정의 / 핵심 성질

### 1.1 배열

#### 정의

같은 자료형의 원소들을 연속된 메모리 공간에 차례대로 저장하는 자료구조이다. 각 원소는 인덱스로 구분한다.

#### 구조

```
인덱스:    0     1     2     3     4
값:     [ 10 |  20 |  30 |  40 |  50 ]
주소:     100   104   108   112   116      (int 4바이트, 시작 주소 100)
```

#### 성질

| 성질 | 설명 |
| --- | --- |
| 임의 접근이 `O(1)`이다 | 주소 = 시작 주소 + 인덱스 × 원소 크기로 바로 계산된다 |
| 중간 삽입·삭제가 `O(n)`이다 | 빈틈없이 연속되어야 하므로 뒤 원소를 모두 밀거나 당겨야 한다 |
| 크기를 바꾸기 어렵다 | 뒤쪽 메모리가 비어 있다는 보장이 없어 새로 할당하고 복사해야 한다 |
| 캐시 효율이 좋다 | 이웃한 원소가 메모리에서도 붙어 있다 |

### 1.2 다차원 배열의 주소 계산

#### 정의

메모리는 1차원이므로 2차원 이상의 배열은 일정한 순서로 펼쳐 저장한다.
- 행 우선(row-major): 한 행을 다 채운 뒤 다음 행으로 간다. C, C++, Java, Python(NumPy)
- 열 우선(column-major): 한 열을 다 채운 뒤 다음 열로 간다. Fortran, MATLAB, R

#### 구조

```
A =  a  b  c
     d  e  f

행 우선 저장:  a  b  c  d  e  f
열 우선 저장:  a  d  b  e  c  f
```

#### 주소 공식

원소 크기 `w`, 시작 주소 `α`, 배열 `A[l1..u1][l2..u2]`, 행 수 `R = u1 − l1 + 1`, 열 수 `C = u2 − l2 + 1`

| 방식 | 공식 | 설명 |
| --- | --- | --- |
| 1차원 `A[l..u]` | `α + (i − l)·w` | 앞에 `i − l`개가 있다 |
| 2차원 행 우선 | `α + ((i − l1)·C + (j − l2))·w` | 앞에 완전한 행 `i − l1`개(각 C개)와, 같은 행에서 `j − l2`개가 있다 |
| 2차원 열 우선 | `α + ((j − l2)·R + (i − l1))·w` | 앞에 완전한 열 `j − l2`개(각 R개)와, 같은 열에서 `i − l1`개가 있다 |
| 3차원 행 우선 `A[0..u1−1][0..u2−1][0..u3−1]` | `α + (i·u2·u3 + j·u3 + k)·w` | 앞에 2차원 판 i개, 행 j개, 원소 k개가 있다 |

### 1.3 특수 행렬

#### 삼각 행렬

주대각선 아래(또는 위)만 값이 있는 행렬이다. n×n 하삼각 행렬은 `n(n+1)/2`개만 저장하면 된다.

```
행 0:  A00                    → 1차원 위치 0
행 1:  A10 A11                → 1, 2
행 2:  A20 A21 A22            → 3, 4, 5
행 3:  A30 A31 A32 A33        → 6, 7, 8, 9
```

| 성질 | 설명 |
| --- | --- |
| 0-based 행 우선 저장에서 `A[i][j]`의 위치는 `i(i+1)/2 + j`이다 | 행 i 앞에 `1 + 2 + … + i = i(i+1)/2`개가 있다 |
| 상삼각 행렬은 `A[i][j] = B[j][i]`로 하삼각처럼 다룬다 | 전치하면 하삼각이 된다 |
| 대칭 행렬도 절반만 저장한다 | `A[i][j] = A[j][i]` |

#### 희소 행렬 (sparse matrix)

원소 대부분이 0인 행렬이다. 0이 아닌 원소만 `<행, 열, 값>`의 3원소로 저장한다.

```
행렬                     3원소 표현 (행, 열, 값)
0  0  3  0               [0]  4  4  3     ← 행 수, 열 수, 0 아닌 원소 수
0  0  0  0               [1]  0  2  3
5  0  0  0               [2]  2  0  5
0  0  0  7               [3]  3  3  7
```

| 성질 | 설명 |
| --- | --- |
| 원소는 행 우선 순서로 정렬해 둔다 | 행렬 연산(전치, 곱셈)을 순서대로 처리하기 위해서이다 |
| 단순 전치는 `O(열 수 × 원소 수)`이다 | 열마다 전체 원소를 훑어 그 열의 원소를 찾는다 |
| 빠른 전치는 `O(열 수 + 원소 수)`이다 | 열별 원소 수를 먼저 세어 각 열의 시작 위치를 구한 뒤, 한 번 훑으며 바로 제자리에 놓는다 |

#### 다항식

| 표현 | 방법 | 특징 |
| --- | --- | --- |
| 밀집 표현 | `coef[i]` = `xⁱ`의 계수 | `x¹⁰⁰⁰ + 1`처럼 차수가 크고 항이 적으면 낭비가 심하다 |
| 희소 표현 | `(계수, 지수)` 쌍을 지수 내림차순으로 저장 | 덧셈은 두 다항식을 병합하듯 진행하여 `O(m + n)`, 곱셈은 모든 항의 쌍을 곱하므로 `O(m·n)`이다 |

### 1.4 연결 리스트

#### 정의

각 원소(노드)가 데이터와 다음 노드의 주소(링크)를 함께 저장하고, 링크를 따라 이어진 자료구조이다.

#### 등장 배경

배열은 삽입·삭제 때 원소를 밀고 당겨야 하고 크기가 고정되어 있다. 노드를 메모리 여기저기에 두고 링크만 바꾸면 원소 이동 없이 삽입·삭제할 수 있고 크기도 자유롭게 늘릴 수 있다.

#### 구조

```
단일 연결 리스트
head → [10 | •] → [20 | •] → [30 | null]

이중 연결 리스트
null ← [• | 10 | •] ⇄ [• | 20 | •] ⇄ [• | 30 | •] → null

원형 연결 리스트
[10 | •] → [20 | •] → [30 | •]
   ↑                       │
   └───────────────────────┘
```

#### 종류

| 종류 | 정의 | 특징 |
| --- | --- | --- |
| 단일 연결 리스트 | 다음 노드 링크만 가진다 | 이전 노드로 갈 수 없다 |
| 이중 연결 리스트 | 이전·다음 링크를 모두 가진다 | 양방향 이동, 노드 자신만 알면 삭제할 수 있다 |
| 원형 연결 리스트 | 마지막 노드가 첫 노드를 가리킨다 | 마지막 노드 포인터만 있으면 맨 앞·맨 뒤 삽입이 모두 `O(1)`이다 |
| 헤더(더미) 노드 | 데이터 없는 노드를 맨 앞에 둔다 | 빈 리스트, 첫 노드 삽입·삭제 같은 예외 처리가 사라진다 |

#### 성질

| 성질 | 설명 |
| --- | --- |
| 위치를 알면 삽입·삭제가 `O(1)`이다 | 앞뒤 링크만 바꾼다 |
| k번째 원소 접근이 `O(n)`이다 | 주소를 계산할 수 없어 처음부터 따라가야 한다 |
| 단일 연결 리스트에서 노드 삭제에는 이전 노드가 필요하다 | 이전 노드의 링크를 바꿔야 한다 |
| 링크 공간이 추가로 든다 | 노드마다 단일은 1개, 이중은 2개의 포인터가 있다 |

### 1.5 동적 배열

#### 정의

용량이 가득 차면 더 큰 배열을 새로 할당하고 원소를 옮겨, 크기가 자동으로 늘어나는 배열이다. Python의 `list`, Java의 `ArrayList`가 해당한다.

#### 성질

| 성질 | 설명 |
| --- | --- |
| 끝 삽입이 분할상환 `O(1)`이다 | 용량을 2배씩 늘리면 n번 삽입 동안 복사 총량이 `1 + 2 + 4 + … < 2n`이다 |
| 확장하는 순간은 `O(n)`이다 | 모든 원소를 복사한다 |
| 일정한 크기(+10 등)씩 늘리면 분할상환 `O(n)`이 된다 | 확장이 너무 자주 일어나 복사 총량이 `O(n²)`이 된다 |
| 줄일 때는 1/4 이하가 되면 절반으로 줄인다 | 1/2에서 줄이면 경계에서 삽입·삭제를 반복할 때 확장과 축소가 번갈아 일어난다 |

### 용어 정리

- **노드**: 데이터와 링크를 묶은 연결 리스트의 원소
- **링크(포인터)**: 다른 노드의 주소
- **헤드**: 첫 노드를 가리키는 포인터
- **임의 접근 (random access)**: 위치를 알면 바로 접근하는 방식
- **순차 접근 (sequential access)**: 처음부터 차례로 따라가야 하는 방식
- **행 우선 / 열 우선**: 다차원 배열을 행 단위 / 열 단위로 펼쳐 저장하는 방식

## 2. 연산별 시간복잡도

| 연산 | 배열 | 동적 배열 | 단일 연결 리스트 | 이중 연결 리스트 |
| --- | --- | --- | --- | --- |
| 인덱스 접근 | `O(1)` | `O(1)` | `O(n)` | `O(n)` |
| 탐색 | `O(n)` | `O(n)` | `O(n)` | `O(n)` |
| 맨 앞 삽입/삭제 | `O(n)` | `O(n)` | `O(1)` | `O(1)` |
| 맨 뒤 삽입 | 불가(고정) | 분할상환 `O(1)` | `O(1)` (tail 유지 시) | `O(1)` |
| 맨 뒤 삭제 | `O(1)` | `O(1)` | `O(n)` (이전 노드 찾아야 함) | `O(1)` |
| 중간 삽입/삭제 (위치 알 때) | `O(n)` | `O(n)` | `O(1)` (이전 노드 알 때) | `O(1)` |
| 추가 공간 | 없음 | 여유 용량 | 노드당 링크 1개 | 노드당 링크 2개 |

## 3. 동작 과정

### 2차원 주소 계산

`int A[1..5][1..4]` (w = 4바이트), 시작 주소 100, `A[3][2]`의 주소.
- R = 5, C = 4
- 행 우선: `100 + ((3−1)·4 + (2−1))·4 = 100 + 9·4 = 136`
- 열 우선: `100 + ((2−1)·5 + (3−1))·4 = 100 + 7·4 = 128`

### 하삼각 행렬 위치

n = 4, 0-based, `A[3][1]` 위치: `3·4/2 + 1 = 7`
```
행0: A00                 → 0
행1: A10 A11             → 1 2
행2: A20 A21 A22         → 3 4 5
행3: A30 A31 A32 A33     → 6 7 8 9
```

### 단일 연결 리스트 삽입 (p 다음에 x)

```
x.next = p.next   # 1. 새 노드가 뒤를 먼저 잡음
p.next = x        # 2. 앞 노드가 새 노드를 가리킴
```
순서를 바꾸면 `p.next`가 먼저 덮여 원래 뒤쪽 노드를 잃음.

### 이중 연결 리스트

삽입 (p 다음에 x)
```
x.prev = p
x.next = p.next
p.next.prev = x
p.next = x
```
삭제 (x 자신)
```
x.prev.next = x.next
x.next.prev = x.prev
```

### 단일 연결 리스트 뒤집기

```
prev = None, cur = head
반복: nxt = cur.next → cur.next = prev → prev = cur → cur = nxt
끝나면 head = prev
```
`1 → 2 → 3` → `3 → 2 → 1`, `O(n)` 시간, `O(1)` 공간.

### 희소 행렬 빠른 전치

원소 `(0,0,15) (0,3,22) (0,5,−15) (1,1,11) (1,2,3) (2,3,−6) (4,0,91) (5,2,28)`, 열 6개.
1. 열별 원소 수: 열0: 2, 열1: 1, 열2: 2, 열3: 2, 열4: 0, 열5: 1
2. 시작 위치(누적): 열0: 0, 열1: 2, 열2: 3, 열3: 5, 열4: 7, 열5: 7
3. 원본을 순서대로 읽으며 `(열, 행, 값)`을 해당 열 시작 위치에 넣고 위치 +1

## 5. Python 구현 / 라이브러리

- `list`는 객체 포인터의 동적 배열. 확장 시 약 1.125배 + α로 여유 할당
- 연결 리스트는 표준 구현이 없음. 양끝 삽입·삭제가 필요하면 `collections.deque` (블록 단위 이중 연결 리스트)

```python
class Node:
    def __init__(self, val, nxt=None):
        self.val = val
        self.next = nxt


def reverse(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next
    return prev
```
