# algorithm

알고리즘 문제 풀이를 기록하는 저장소

## 플랫폼

- 백준 온라인 저지 (BOJ)
- 프로그래머스 (PGS)
- NeetCode (NTC)

## 사용 언어

- Python
- SQL
- JavaScript

## 디렉터리 구조
```
algorithm/
├─ Baekjoon/      백준 풀이
│  ├─ BFS/
│  ├─ DP/
│  ├─ Dijkstra/
│  └─ ...
├─ programmers/   프로그래머스 풀이
│  ├─ DFS/
│  ├─ SQL/
│  └─ ...
└─ NeetCode/      NeetCode 풀이
   ├─ BFS/
   └─ ...
```

## 커밋 컨벤션

```
solve: [플랫폼] 문제이름 / 난이도
```

| ------------ | ---- |
| 백준         | BOJ  |
| 프로그래머스 | PGS  |
